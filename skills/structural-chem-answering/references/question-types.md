# 题型总览与判别（18 类）

判题型看**题干要你交什么东西**，不看章节。同一个知识点可以出三种题型：填空要符号、计算要过程、回答要一句判据。
下面每一类给：信号 → 必写 → 工具 → 采分点 → 陷阱 → 出处（真题/教材习题编号可复核）。

出处代号：**A** = 南开试卷(A)答案；**B** = 模型实习答案；**C** = 教材习题（OCR 行号可查）。

## 一、量子化学基础与原子结构（6 类）

### 1. 写方程类
- **信号**：`写出下体系的 Schrödinger 方程`、`写出 He 原子/Li²⁺ 的方程并说明各项意义`
- **必写**：动能项（每个粒子一个）+ 核对每个电子的吸引项 + 电子间互斥项 + 核间互斥项 + `=Eψ`
- **工具**：无（纯符号题）。可用 `sc_hydrogen_orbital(n,l,m)` 核对该体系能级量级。
- **采分点**：项数是否齐（H₂ 有 6 项 + 1 个互斥项 + 1 个 R）、符号（吸引为负）、是否标 `=Eψ`。
- **陷阱**：H₂ 忘核间互斥 `+1/R`；把电子互斥写成吸引；用原子单位与 SI 混写（一会 `ħ²/2m` 一会 `h²/8π²m`）。
- **出处**：A 一-1（He⁺ 与 H₂）；C 习题 2.15（He 原子 + 中心力场假设）、2.16（Li²⁺）。

### 2. 势箱与共轭分子吸收
- **信号**：`一维/三维势箱`、`箱长 2L`、`估算共轭分子吸收波长`、`简并度`
- **必写**：`E=n²h²/8mL²` → 电子填充（Pauli）→ 跃迁 `ΔE` → `λ=hc/ΔE`
- **工具**：`sc_particle_box(n, L_pm, dim)`（三维简并度、零点能、HOMO→LUMO 一步给全）
- **采分点**：能级式 → 填充 → 跃迁选择 → ΔE 代入 → λ。
- **陷阱**：漏 `n²`；箱长用 `2L` 时代入仍写 `L`；共轭分子忘记"势箱长 = 共轭链长 + 两端延伸"（教材：`l=(248r+565)pm`、花菁染料）。
- **出处**：A 二-3（箱长 2L，n=2，求 0~L/2 概率、概率密度、动能）；C 习题 1.14–1.17、1.20、1.21（苯环 π 电子用圆环能级）。

### 3. 类氢原子状态量
- **信号**：`n,l,m 给定，求节面/能量/角动量/最可几半径/概率`
- **必写**：径向节面 `n−l−1`、角节面 `l`、总节面 `n−1`；`E=−13.6Z²/n² eV`；`|L|=√(l(l+1))ħ`；`Lz=mħ`
- **工具**：`sc_hydrogen_orbital(n,l,m)`
- **采分点**：三个节点数分别答；量子数对应；`<r>` 与最可几半径区分。
- **陷阱**：把"概率密度最大"当最可几半径（后者是 `r²R²` 极大，1s 在 `r=a₀`）；2s 的径向节面位置答成"在核上"。
- **出处**：A 一-15（ψ₃₁₀ 三张图）；C 习题 2.7（P(r)=0.1 的 r）、2.9（E、|M|、夹角、节面）、2.11（2s 的 D 函数节点与极大）。

### 4. 屏蔽与有效核电荷
- **信号**：`用 Slater 法计算电离能`、`有效核电荷`、`比较 2s 与 2p 能量`
- **必写**：分组 → 逐组贡献 → `σ` → `Z*=Z−σ` → `E=−13.6Z*²/n*²`
- **工具**：`sc_slater(config, target)`
- **采分点**：分组是否对（`1s | 2s2p | 3s3p | 3d | 4s4p…`）、同组系数（0.35，1s 为 0.30）、`n−1` 层 0.85、更内 1.00、d/f 左侧一律 1.00。
- **陷阱**：把 `3d` 对 `4s` 的贡献算成 1.00（应为 **0.85**，因 3d 属 n−1 层）；用 Slater 结果论证"4s 先于 3d 填充"（此法在该比较上失效）。
- **出处**：C 习题 2.16(5)、2.19（Be 四级电离能并与氧化态联系）、2.20（Na、F 的有效半径）。

### 5. 光谱项与基项
- **信号**：`写出 d² 组态的所有光谱项`、`基谱项/基支项`、`微观状态数`
- **必写**：等价/非等价判定 → 组态 → 光谱项清单 → **微观状态数校验** → Hund 三规则 → 基项与基支项
- **工具**：`sc_spectroscopic_terms("d2"|"p2"|"3d6"|"p d")`
- **采分点**：项符号上下标（³F 而非 3F）、J 值列表、校验数（d²: 45；p²: 15）、基项按 S→L→J 三步。
- **陷阱**：等价电子用可区分组合（d² 数成 100）；`3d⁶` 过半满仍取 `J=|L−S|`（应 `J=L+S=4` → ⁵D₄）；忘记 ³D 的 15 个微观状态。
- **出处**：A 一-2（³D：15 个微观状态、`L=√6ħ`、`S=√2ħ`、J=3,2,1）、一-3（Cu ²S₁/₂）、一-4（Fe 基项 ⁵D₄）、一-5（d² 五项 + 基项 ³F）；C 习题 2.21–2.24。

### 6. 波函数叠加与测量概率
- **信号**：`ψ=C₁ψ₂₁₀+C₂ψ₃₁₁+…，求能量平均值/某能量出现的概率/角动量平均值`
- **必写**：`<E>=Σ|cᵢ|²Eᵢ`；`P(Eᵢ)=|cᵢ|²`；`<Lz>=Σ|cᵢ|²mᵢħ`；`|L|=√(l(l+1))ħ`（同 l 时是确定值，概率 1）
- **工具**：`sc_superposition(terms)`
- **采分点**：系数平方是否归一（`Σ|c|²=1`）→ 每个本征值的概率 → 平均值 → 角动量分量的概率。
- **陷阱**：把 `<Lz>` 写成 `Σ|c|²·m`（漏 ħ）；问"角动量值出现的概率"时把 `|L|` 当成 `Lz`；本征能量写错 n（ψ₂₁₀ 的 E 只由 n=2 决定）。
- **出处**：A 一-13（能量平均值 `–[C₁²/8+(C₂²+C₃²)/18] a.u.`＝`–[…]/R`、−R/4 的概率 C₁²、`<Lz>=C₂²ħ`）；C 习题 1.16、1.22、2.12。

## 二、对称性与群论（4 类）

### 7. 点群判定与对称元素
- **信号**：`给出下列分子所属点群`、`属何种点群`、`国际符号 m2̄（4̄2m）对应的熊夫利符号`
- **必写**：判据链（最高轴次 → 有无 n 个 ⊥C₂ → 有无 σh / σd → 记号）；表格题只写记号。
- **工具**：`sc_point_group(atoms)`、`sc_symmetry_elements(pg)`
- **采分点**：熊夫利记号（不是国际记号，除非题目问"国际符号"）、大小写、d/h/v 下标。
- **陷阱**：丙二烯/联苯 90°/四甲基环辛四烯判成 D2h（实为 **D2d / S4**）；椅式环己烷判成 D6h（实为 **D3d**）；写成 `C2V`。
- **出处**：A 一-6（10 个分子）、一-9（`m2̄` → D2d）；B 实习一（29 个分子，含对称中心一列）、实习三（32 个晶体学点群与国际符号三位方向）。

### 8. 特征标表查表与约化
- **信号**：`查特征标表`、`某基函数属哪个不可约表示`、`把 Γ 约化`、`用对称性化简久期行列式`
- **必写**：类顺序 → 该表示的 χ 行 → `n_i=(1/h)Σ_c g_c χ_i(c) χ_Γ(c)` 逐项代入 → 检验 `Σ n_i·dim_i = 总自由度`
- **工具**：`sc_character_table(pg)`（含 `basis`）、`sc_reduce_representation(pg, chars)`
- **采分点**：约化式的逐项代入（不是只给结果）、`chars` 顺序与表的类顺序一致、约化结果加总校验。
- **陷阱**：不校验加总（3N 对不上）；把 `chars` 按自己记的顺序给（E/C₂/σ 各表不同）。
- **出处**：A 二-1（用对称性把 3×3 久期行列式拆成"对称 S"与"反对称 A"两支，这是约化思想的具体用法）。

### 9. 3N 振动分解与选律
- **信号**：`求 Γ_3N`、`有多少个振动模式`、`哪些 IR 活性/哪些 Raman 活性`、`有无静默模式`
- **必写**：`Γ_3N` → 减 `Γ_trans`（x,y,z）与 `Γ_rot`（Rx,Ry,Rz）→ `Γ_vib` → IR 判据（与 x,y,z 同表示）、Raman 判据（与二次函数同表示）
- **工具**：`sc_normal_modes(pg, n_atoms, is_linear)`、`sc_selection_rules(pg)`
- **采分点**：线形用 `3N−5`；活性清单分组列出；互斥规则要说（有 i 的分子）。
- **陷阱**：忘减平动转动；IR/Raman 判据互换；有中心的分子答出"某模式双重活性"。
- **出处**：教材 H₂O（`Γ_vib=2A₁+B₁`，全活性）、SF₆（`Γ_vib=A₁g+E_g+2T₁u+T₂g+T₂u`）；本课程作业常用苯、NH₃、CO₂。

### 10. 偶极矩与旋光性判定
- **信号**：`有无偶极矩`、`有无旋光性`、`指出哪些点群的分子具有偶极矩/旋光性`
- **必写**：点群 → 判据 → `有/无`（问方向才写"沿 C₂ 轴/在镜面内"）
- **工具**：`sc_selection_rules(pg)`
- **采分点**：三张清单（有 i / 有偶极矩 / 有旋光性）能否默写；偶极矩方向。
- **陷阱**：以为"无 i 就有偶极矩"（D₂、D₃ 无 i 但无偶极矩）；把 D₂d 当有偶极矩。
- **出处**：A 一-6；B 实习一"二、总结"三行答案：
  `有对称中心：C2h, C4h, C6h, D2h, D4h, D6h, D3d, D5d, Th, Oh`；
  `具有偶极矩：C1, C2, C3, C4, C5, C6, C2v, C3v, C4v, C5v, C6v`（再加 C_s 与 C∞v，见 A 表内 CO 与溴代吡啶）；
  `具有旋光性：C1, C2, C3, C4, C5, C6, D2, D3, D4, D5, D6, T, O`。

## 三、分子轨道与化学键（4 类）

### 11. HMO 与分子图
- **信号**：`用 HMO 法求…的离域 π 键`、`求键级/电荷密度/自由价`、`画出分子图`、`比较键长`
- **必写**：久期行列式 → 展开解 x → `E=α+xβ` → 回代求系数 → 归一化 → `q_r=Σn_i c_ir²`、`P_rs=Σn_i c_ir c_is`、`F_r=√3−Σ_{s邻接}P_rs` → 分子图 → 比较结论一句
- **工具**：`sc_huckel(topology/adj, n_electrons)`
- **采分点**：行列式（过程分）、x 值、能级带 α/β、三组数值、分子图画全（q 标原子、P 标键、F 箭头）。
- **陷阱**：自由价把不相邻键级也减掉；能级漏 β；分子图写"略"；比较题写推导而不给一句结论。
- **出处**：A 二-1（环烯丙基正离子全套：`q=0.667`、`P=0.667`、`F=0.398`、④ 一句话比较）、回答题-2（富烯：直接给 6 个 ψ、要求画分子图 + 指反应位点，答案 `③ 反应位置在3、6 位`）。

### 12. 芳香性判定
- **信号**：`是否芳香`、`有无芳香性`、`为什么环辛四烯不芳香`
- **必写**：平面 + 环状（或环状共轭体系）+ 完全共轭 + 4n+2 四个条件逐条
- **工具**：`sc_aromaticity(n_pi, n_atoms)`、`sc_huckel`（看能级是否全充满成键轨道）
- **采分点**：四个条件都要出现；反例（环辛四烯盆形、环丁二烯 4π 反芳香）。
- **陷阱**：只算 4n+2 不说平面性；把"非苯芳香"（环丙烯正离子 2π、环戊二烯负离子 6π）判成不芳香。
- **出处**：教材 Hückel 章；本课程常与 HMO 联考（正/负离子对比）。

### 13. 双原子分子 MO 与键级磁性
- **信号**：`写出分子轨道组态`、`键级`、`有无磁性`、`键长趋势`
- **必写**：组态（按能级顺序，标 σ/π、成/反键、填充）→ `键级=(n_b−n_a)/2` → 单电子数 → 顺磁/抗磁
- **工具**：`sc_diatomic_mo(n_electrons, period)`
- **采分点**：能级顺序（N₂ 及更轻 σ2p 在 π 之上；O₂、F₂ 反之）、键级、磁性三样齐。
- **陷阱**：顺序写反；键级忘除 2；把 O₂ 判成抗磁。
- **出处**：A 一-7（NO：`…π⁴5σ²2π¹`，键级 **2.5**，有磁性）、一-8（两轨道沿 z 接近形成 σ 还是 σ*）；C 习题 3.x 与 3.6 节 UPS 相关（Ar 2:1 分裂 → l=1，见习题 3.34）。

### 14. VSEPR 与构型杂化
- **信号**：`判断空间构型`、`中心原子杂化`、`键角`、`属何点群`
- **必写**：价层电子对数（成键对 + 孤对）→ AX_mE_n → 构型名 → 点群 → 键角（必要时说"略小于/大于理想值"）
- **工具**：`sc_vsepr(central, ligands, lone_pairs)`
- **采分点**：电子对构型 vs 分子构型分开；孤对位置（平伏/直立）；点群。
- **陷阱**：SF₄ 答"四面体"（是**跷跷板 C₂v**）；AX₃E₂ 答成三角锥（是 **T 形 C₂v**）；把 VSEPR 记号 AX₅ 与"五配位"混为一谈。
- **出处**：教材 VSEPR 节；本课程 SF₄/ClF₃/XeF₄ 常考（对应 Td/C₂v/C₂v/D₄h 判点群联动）。

## 四、晶体与配位（4 类）

### 15. 晶系 · 晶面 · 衍射
- **信号**：`属何晶系`、`晶面指标`、`面间距`、`衍射角与衍射指标`
- **必写**：晶系（边长关系 + 角关系）→ `(hkl)`（取倒数、通分、互质）→ `d` 公式 → `2dsinθ=nλ`
- **工具**：`sc_unit_cell`、`sc_miller_indices`、`sc_d_spacing`
- **采分点**：晶系判据（正三棱柱 → **六方**，别被"三方"误导）；指标顺序 `(hkl)` 对应 x,y,z；衍射指标要按消光条件筛。
- **陷阱**：忘取倒数；负指数不标；立方与六方的 d 公式混用（六方 `1/d²=4(h²+hk+k²)/3a²+l²/c²`）。
- **出处**：A 一-10（正三棱柱 → 六方）、一-11（a/2,b/3,c/4 → `(234)`）、二-2⑤（bcc：h+k+l=奇数消光 → 110, 200, 211，`θ=12.0°/17.1°/21.1°`）；B 实习二（石墨 `a=b=2.46Å, 120º`）、实习三（由外形判晶系与 32 点群）。

### 16. 点阵型式 · 结构基元 · 堆积 · 空隙
- **信号**：`属何种点阵型式`、`一个结构基元代表什么`、`一个晶胞含几个结构基元`、`负离子作何堆积`、`填入何种空隙、占几分之几`、`空间利用率`
- **必写**：点阵型式（+ 布拉威格子）→ 结构基元内容 → 晶胞内各离子数 → 堆积型式（A1/A2/A3/A4）→ 空隙类型与占用分数 → 空间利用率（3 位）
- **工具**：`sc_packing(kind)`、`sc_cell_content(...)`、`sc_unit_cell(...)`
- **采分点**：`点阵型式`≠`堆积型式`；`结构基元`≠`晶胞内原子数`；分数坐标要按面/棱/顶点折算。
- **陷阱**：金刚石 8 原子/胞但**4 个结构基元**（1 基元 = 2 个 C）；空间利用率忘乘胞内原子数。
- **出处**：A 一-12（ZrO₂：立方面心、4 基元、8 个 O²⁻、CN 8:4、立方简单、立方体空隙、1/2、**58.9%**，并要求画 110 面排布）、二-2①②（K：立方晶系、立方体心、1 个原子/基元、2 个基元/胞）、回答题-1；B 实习四（A1/A2/A3/A4 全表）。

### 17. 离子晶体 · 半径比 · 配位多面体
- **信号**：`负离子配位多面体的形状`、`半径比`、`属何种结构型式`、`正离子占该类空隙的分数`
- **必写**：`r₊/r₋` → 落入区间 → 配位数与多面体；结构型式六型对照（堆积方式 + CN + 空隙类型 + 占用分数）
- **工具**：`sc_radius_ratio(r_plus, r_minus)`、`sc_packing`
- **采分点**：区间临界值（0.155 / 0.225 / 0.414 / 0.732 / 1.0）；"正离子所占空隙的分数"是分子/分母都给（如 4/8）。
- **陷阱**：半径比用反；NaCl 型答"立方体空隙"（应为**正八面体**）；CaF₂ 型把 F⁻ 说成 A1 堆积（实为**立方简单**）。
- **出处**：A 一-14（KBr：133/328 → 八面体）、回答题-1（K⁺/F⁻ 联合组成 A1，Mn²⁺ 在八面体空隙占 1/4）；B 实习五（六型全表 + 四个临界半径比 0.732/0.414/0.225/0.155）。

### 18. 晶体场 · CFSE · 磁性
- **信号**：`晶体场分裂`、`CFSE`、`高自旋还是低自旋`、`磁矩`、`颜色/光谱化学序列`
- **必写**：d 电子数 → 几何构型 → 分裂（t₂g/e_g 或 e/t₂）→ 与成对能 P 比较 → 组态 → 单电子数 → `μ=√(n(n+2)) BM` → CFSE（Dq 为单位）
- **工具**：`sc_crystal_field(d_n, geometry, ligand, pairing_energy_cm1)`、`sc_spectrochemical_series(ligand)`
- **采分点**：组态与自旋标签必须自洽；CFSE 的符号与系数（八面体 `−0.4n(t₂g)+0.6n(e_g)`）；磁矩公式。
- **陷阱**：`t₂g⁶e_g⁰` 配"高自旋"（自相矛盾）；`μ` 用 `n+2`；CFSE 忘乘 Dq；四面体 Δt 用成 Δo。
- **出处**：教材配位场章（本课程核心计算题之一）；契约验收样例：Fe²⁺ d⁶ 八面体弱场 → 4 个单电子、`μ=4.90 BM`。

## 五、题型判别的一句话规则

1. **题干有一个"求确定量"** → 计算题：过程式 + 数值 + 单位 + 一句结论。
2. **题干有"下表/填空/选择"** → 只写符号，不写理由（除题干明问理由）。
3. **题干有"画"** → 作图题，图占分。
4. **题干有"为什么/说明/解释"** → 一句判据，≤ 22 字，起头用"因为/由于/属…故"。
5. **题干有"比较/排序"** → 先给关系（`A > B > C` 或一句话比较），再给一个可命名原因。
6. **判不出来** → 看这道题想让你交的是符号、数、图还是句子，四选一，然后照上表取骨架。
