# 配位化合物：晶体场 · CFSE · 磁性 · 异构

本课配位场部分只考四件事：**分裂 → 组态 → CFSE/自旋态 → 磁矩**，再挂一点异构与颜色解释。
凡 d 电子数确定，一律 `sc_crystal_field` 算，不要背表背错符号。

---

## 一、五种 d 轨道的分裂

| 几何构型 | 分裂结果 | 分裂能 | 备注 |
|---|---|---|---|
| 八面体 Oh | 低能 `t2g`（dxy, dxz, dyz）+ 高能 `e_g`（dz², dx²−y²） | **Δo = 10Dq** | 最常考 |
| 四面体 Td | 低能 `e`（dz², dx²−y²）+ 高能 `t2`（dxy, dxz, dyz） | **Δt = (4/9)Δo** | 分裂小 → 几乎都高自旋 |
| 平面四方 D4h | dxz=dyz < dz² < dxy < dx²−y² | 最大 | 分裂极大 → 几乎都低自旋 |
| 直线形 | dz² 最高 | — | 少考 |
| 立方体（8 配位） | 与四面体反向：`t2` 在上、`e` 在下 | Δ = (8/9)Δt | 少考 |

**符号方向**：八面体里 d 电子优先占 `t2g`（能量降低 `−4Dq`），进入 `e_g` 升高 `+6Dq`。
四面体反过来：`e` 降 `−6Dq`、`t2` 升 `+4Dq`（以 Dq 计的相对值）。

## 二、CFSE（晶体场稳定化能）

```
八面体：CFSE = [−0.4·n(t2g) + 0.6·n(eg)] × 10Dq
四面体：CFSE = [−0.6·n(e)  + 0.4·n(t2)] × Δt
考虑成对能时：低自旋组态再 + n_对 × P（P 为成对能，使 CFSE 变小，即低自旋"代价"）
```

八面体 CFSE 与单电子数全表（单位 Dq；未加成对能修正）：

| d^n | 高自旋组态 | CFSE | 单电子 | 低自旋组态 | CFSE | 单电子 |
|---|---|---|---|---|---|---|
| d⁰ | t2g⁰eg⁰ | 0 | 0 | — | — | — |
| d¹ | t2g¹ | −4 | 1 | — | — | — |
| d² | t2g² | −8 | 2 | — | — | — |
| d³ | t2g³ | −12 | 3 | — | — | — |
| d⁴ | t2g³eg¹ | −8 | 4 | t2g⁴ | −16 (+P) | 2 |
| d⁵ | t2g³eg² | 0 | 5 | t2g⁵ | −20 (+2P) | 1 |
| d⁶ | t2g⁴eg² | −4 | 4 | t2g⁶ | −24 (+3P) | 0 |
| d⁷ | t2g⁵eg² | −8 | 3 | t2g⁶eg¹ | −18 (+3P) | 1 |
| d⁸ | t2g⁶eg² | −12 | 2 | — | — | — |
| d⁹ | t2g⁶eg³ | −6 | 1 | — | — | — |
| d¹⁰ | t2g⁶eg⁴ | 0 | 0 | — | — | — |

**高/低自旋的判据只有一条**：`Δo > P` → 低自旋（强场）；`Δo < P` → 高自旋（弱场）。
第一过渡系多为弱场高自旋（除 CN⁻、CO 等强场配体）；第二、三过渡系 Δo 大，几乎都是低自旋。

## 三、磁矩

```
μ = √(n(n+2)) BM          n = 单电子数
n:  1     2     3     4     5
μ: 1.73  2.83  3.87  4.90  5.92
```

测得的 μ 与"只考虑自旋"的值略有偏差（有轨道贡献），题目给实验值反推 n 时取最接近的整数。
真题级别的标准例：Fe²⁺（d⁶）八面体弱场 → `t2g⁴eg²`，n=4，`μ=√(4×6)=4.90 BM`，高自旋。

**答磁矩题的固定四句**：d 电子数 → 几何构型 → 组态（t2g/eg 上标） → n 与 μ 与磁性质。

## 四、光谱化学序列（配体由弱到强）

```
I⁻ < Br⁻ < S²⁻ < SCN⁻(S) < Cl⁻ < NO3⁻ < F⁻ < OH⁻ < ox²⁻(草酸根) < H2O
  < NCS⁻(N) < NH3 < en < bipy < phen < NO2⁻ < CN⁻ ≈ CO
```

用法：
- 判断同一金属不同配合物的 Δo 大小 → 按序列定位。
- 判断高/低自旋 → 强场配体（右侧）倾向低自旋。
- 解释颜色深浅/波长移动 → Δo 越大，吸收波长越短（蓝移）。

中心离子对 Δo 的影响：**氧化态越高、周期越靠下 → Δo 越大**（3d < 4d < 5d）。

## 五、颜色与 d-d 跃迁

```
吸收能量 Δo 的光 → 透过/反射其补色 → 我们看到的颜色。
Δo 增大 → 吸收波长变短 → 颜色向红端方向变化（补色）。
```

答题句式：`该配合物 d 轨道未充满，d-d 跃迁吸收可见光，故显色；Δo 越大，吸收波长越短。`
**注意**：d⁰ 与 d¹⁰ 无 d-d 跃迁 → 无色（如 [Zn(H2O)6]²⁺、[Sc(H2O)6]³⁺）。

## 六、Jahn-Teller 效应（畸变，常作简答）

```
判据：八面体构型下 e_g 轨道简并且不均匀占据 → 发生畸变（拉长/压扁），降低对称性与能量。
典型：d⁹（Cu²⁺，t2g⁶eg³）最强；d⁴ 高自旋（Cr²⁺、Mn³⁺，t2g³eg¹）强；
     t2g 简并但不均占（d¹、d²、d⁷ 低自旋）效应弱。
答法：`Cu²⁺ 为 d⁹，e_g 上 3 个电子占据不均，产生 Jahn-Teller 畸变，故 [CuCl4]²⁻/Cu(II) 配合物常见拉长八面体。`
```

## 八、异构（考"有几种异构体"或"哪两个是异构"）

| 类型 | 含义 | 标准例 |
|---|---|---|
| 几何异构 | 配体空间排布不同 | `MA₄B₂`：顺式（C2v，有偶极矩）/ 反式（D4h，无偶极矩）；`MA₃B₃`：面式 fac（C3v）/ 经式 mer（C2v） |
| 光学异构 | 互为镜像不重合 | `[Co(en)3]³⁺`（**D3**，有旋光性）；顺-`[Co(en)2Cl2]⁺`（C2，有旋光性）；反式为 C2h，无旋光 |
| 键合异构 | 两可配体以不同原子配位 | `[Co(NH3)5(NO2)]²⁺`（N 配位，硝基）／`[Co(NH3)5(ONO)]²⁺`（O 配位，亚硝酸根）；`SCN⁻` 的 S 配位与 N 配位 |
| 电离异构 | 内外界离子交换 | `[Co(NH3)5Br]SO4` ／ `[Co(NH3)5SO4]Br` |
| 水合异构 | 水在内界或结晶水 | `[Cr(H2O)6]Cl3` ／ `[Cr(H2O)5Cl]Cl2·H2O` |
| 配位异构 | 配阳离子与配阴离子互换配体 | `[Co(NH3)6][Cr(CN)6]` ／ `[Cr(NH3)6][Co(CN)6]` |

"有几种几何异构体"的计数法：固定一种配体的位置，其余按等价位置分配，再除以对称重复。

## 九、18 电子规则（有机金属/羰基配合物）

```
金属价电子数 + Σ 配体提供电子数 = 18
（CO、CN⁻、NH3、PR3 各给 2；H⁻、Cl⁻ 各给 2；η⁵-Cp 给 6；η⁶-C6H6 给 6；
  金属–金属键各贡献 1）
```

| 配合物 | 计算 | 结论 |
|---|---|---|
| Ni(CO)₄ | 10 + 4×2 = 18 | 稳定 |
| Fe(CO)₅ | 8 + 5×2 = 18 | 稳定 |
| Cr(CO)₆ | 6 + 6×2 = 18 | 稳定 |
| V(CO)₆ | 5 + 12 = 17 | 不稳定（自由基） |

**边界**：18 电子规则只适用于共价性强的羰基/有机金属配合物；离子型配合物（[Co(NH3)6]³⁺ 等）按配位场算，不要套 18 电子。

## 十、答题模板（四行交卷）

```
① 中心离子 Mⁿ⁺ 为 d^x 组态；
② 八面体场分裂：t2g 与 eg 的能量差 Δo = 10Dq；与成对能 P 比较 → 高/低自旋；
③ 组态 t2g^a eg^b，单电子 n，μ = √(n(n+2)) = X BM，顺磁性；
④ CFSE = [−0.4a + 0.6b] × 10Dq = Y Dq。
```

**四个常见自相矛盾**（写完必查）：
1. 组态写 `t2g⁶eg⁰` 却标"高自旋"。
2. 弱场却写低自旋组态。
3. `μ` 用成 `n+2` 或漏开方。
4. CFSE 的符号：**低能轨道要负、高能轨道要正**，符号颠倒会让稳定性排序整题反。

## 十一、工具映射

| 要做的事 | 工具 |
|---|---|
| 分裂、Δo、CFSE、高低自旋、单电子数、磁矩 | `sc_crystal_field(d_n, geometry="octahedral"/"tetrahedral", pairing_energy_cm1, metal, ligand)` |
| 配体在光谱化学序列中的位置与 Δo 相对大小 | `sc_spectrochemical_series(ligand)` |
| 配位构型 → 点群 → 偶极矩/旋光 | `sc_vsepr` → `sc_point_group` → `sc_selection_rules` |

**调用纪律**：`d_n` 按**中心离子的 d 电子数**给（如 Fe²⁺ 给 6，Fe³⁺ 给 5，Co³⁺ 给 6），
不要给"总价电子数"。给了 `pairing_energy_cm1` 才能比较高低自旋；没给就只能按几何构型与配体强弱定性判断。
