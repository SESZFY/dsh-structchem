## 一、Schrödinger 方程怎么写（纯符号题，不调工具）

### 三种写法，先选一种，全题统一

**① SI/教材写法（周公度教材用这个）**
```
[ −(h²/8π²m) ∇² + V ] ψ = Eψ ,   h = Planck 常数
```

**② 原子单位（a.u.，mₑ = e = 4πε₀ = ħ = 1）**
```
[ −½∇² + V ] ψ = Eψ ,   能量单位 Hartree，长度单位 bohr(a₀)
```

**③ 单电子类氢原子（最常考）**
```
SI： [ −(h²/8π²μ)∇² − Z e²/(4πε₀ r) ] ψ = Eψ
a.u.：[ −½∇² − Z/r ] ψ = Eψ
```

### 三个标准例子（真题原题）

**He⁺（单电子，Z=2）**
```
[ −½∇² − 2/r ] ψ = Eψ        （a.u.）
E_n = −2²/2n² = −2/n² Hartree = −54.4/n² eV
```

**H₂（两电子四中心，最容易被扣分的一题）**
```
Ĥ = −½∇₁² − ½∇₂² − 1/r_a1 − 1/r_b1 − 1/r_a2 − 1/r_b2 + 1/r₁₂ + 1/R
[ Ĥ ] ψ = Eψ
```
写全了要能背出四项结构：**两个电子动能 + 四个核对电子吸引（负号）+ 一个电子互斥（正）+ 一个核互斥（正）**。
漏 `+1/R` 或漏 `+1/r₁₂` 是标准失分点（真题第一题就是这一项）。

**Li²⁺（单电子，Z=3，但方程形式与 He⁺ 同）**
```
[ −½∇² − 3/r ] ψ = Eψ ,  ψ_1s = (27/π)^{1/2} e^{−3r}  （a.u.）
```
教材习题 2.16 还要求说明各项意义——**逐项标注符号含义**（动能算符、核对电子的 Coulomb 吸引、总能量、波函数）。

### 多电子原子：中心力场模型要作的假设（习题 2.15 原题）

```
① 每个电子在核与其他电子形成的平均势场中独立运动（单电子近似）；
② 该平均场是球对称的（中心力场近似），V(r) 只与 r 有关；
③ 单电子波函数取类氢形式，但 Z 换成有效核电荷 Z*（可再用 Slater 法估算）；
④ 总波函数 = 各单电子波函数的乘积（或满足 Pauli 原理的 Slater 行列式）。
```

## 二、势箱

### 一维无限深势箱（0 < x < L）

```
ψ_n(x) = √(2/L) · sin(nπx/L)          E_n = n²h²/(8mL²)      n = 1,2,3,…
零点能 E₁ = h²/8mL²；节点数 = n − 1（节点在 x = kL/n，k = 1,…,n−1）
```

概率：`P(a→b) = ∫_a^b |ψ|² dx`；概率密度：`|ψ|²`（**不是 ψ**）。

### 三维势箱（a × b × c）

```
E = (h²/8m)(n_x²/a² + n_y²/b² + n_z²/c²)
```
正方势箱 `a=b=c` 时 `E = (h²/8ma²)(n_x²+n_y²+n_z²)`，简并度由 `n_x²+n_y²+n_z²` 的分解方式决定：

| n² 之和 | 量子数组合 | 简并度 |
|---|---|---|
| 3 | (1,1,1) | 1 |
| 6 | (2,1,1) 的 3 种排列 | 3 |
| 9 | (2,2,1) 的 3 种排列 | 3 |
| 11 | (3,1,1) 的 3 种排列 | 3 |
| 12 | (2,2,2) | 1 |
| 14 | (3,2,1) 的 6 种排列 | **6** |

### 完整例题：箱长 2L、n=2（南开计算题第 3 题，逐步可复算）

```
ψ₂ = √(1/L)·sin(πx/L)（箱长 2L 代入 ψ=√(2/2L)sin(2πx/2L)）
① P(0→L) = ∫₀^L (1/L)sin²(πx/L)dx = 1/2                      → 写在卷面就是 "1/2"
② x=L/2 处概率密度 = (1/L)sin²(π/2) = 1/L
③ E = n²h²/8m(2L)² = 4h²/32mL² = h²/8mL²
```
注意 ③：**箱长变成 2L 时 L 要跟着换**，很多人算成 `4h²/8mL²`。

### 势箱模型用于共轭分子（教材例 1.3.1/1.3.2）

```
① 数 π 电子数（每个双键 2 个，孤对或正离子要算清）
② 电子按 Pauli 填充 n = 1,2,3,…（每个能级 2 个）
③ HOMO → LUMO 的 ΔE = h[(n+1)² − n²]/8mL²
④ λ = hc/ΔE；势箱长 l 取"共轭链长 + 两端延伸"（教材给花菁染料 l = (248r + 565) pm）
```
教材给的实测对照：花菁染料 r=1 计算 311.6 nm ／ 实测 309.0 nm；r=2 计算 412.8 nm ／ 实测 409.0 nm。
→ 说明模型"量级正确、精度有限"，答题时不要把估算值写成精确值。

## 三、类氢原子

### 量子数与观测量

| 量 | 表达式 | 备注 |
|---|---|---|
| 能量 | `E = −13.6 Z²/n² eV = −Z²/(2n²) a.u.` | 只与 n 有关 → 能级简并度 n²（含自旋 2n²） |
| 轨道角动量 | `|L| = √(l(l+1)) ħ` | 只与 l 有关 |
| 角动量 z 分量 | `Lz = m ħ` | m = 0, ±1, …, ±l |
| 径向节面 | `n − l − 1` 个（球面） | 1s: 0；2s: 1；3s: 2；2p: 0 |
| 角节面 | `l` 个（平面/锥面） | s:0，p:1，d:2 |
| 总节面 | `n − 1` | 三个数别互换 |
| 最可几半径（1s） | `a₀/Z` | 由 `D = r²R²` 极大定，**不是**概率密度极大处 |
| 平均半径 | `<r> = (n²a₀/Z)[1 + ½(1 − l(l+1)/n²)]` | 1s 得 1.5a₀/Z |

`D_nl(r) = r²R_nl²(r)` 才是"径向分布函数"；题问"径向分布极大"要解 `dD/dr = 0`。

### 三个常考小判断

- `2s` 与 `2p` 能量相同（同一 n，无外场时严格简并），但**径向分布不同**（2s 有 1 个径向节面，2p 没有）。
- 概率密度极大处（1s 在 r = 0）与最可几半径（1s 在 r = a₀/Z）是两个不同的答案，看题干问哪个。
- 球形界面内电子出现的概率 `P(r) = ∫₀^r |ψ|²·4πr²dr`，`P(r)=0.9` 对应的 r 就是"90% 电子云半径"。

### 作图规范（真题原样，写不出就是丢分）

`ψ₃₁₀` 要三张图，缺一张丢一段分：

```
① 径向密度函数 R²₃₁(r) ~ r 图：3p 的 n−l−1 = 1，要画出一个径向节面（曲线过零点）；
   横轴标 r/a₀，纵轴标 R²，曲线在 0 附近为零、有一峰、穿零一次。
② 角度分布图 Y(θ) ~ θ：p_z 型双球，标 + 与 −，标出节面（xy 平面）。
③ 电子云分布图：用点的疏密表示 |ψ|²，必须"能明确看出角节面（平面）与径向节面（球面）"。
```

教材习题 2.13（1s 的 ψ~r 与 D~r 两图，并证明 D 极大在 r=a₀）、2.14（5 个 3d 轨道轮廓图，标 ±、节面、对称性）是同类作图题的标准答案形态。

## 四、Slater 规则（屏蔽与有效核电荷）

### 分组与贡献

```
分组顺序： [1s] [2s,2p] [3s,3p] [3d] [4s,4p] [4d] [4f] [5s,5p] …

目标为 ns / np 电子：
  同组其他电子           0.35 （1s 组内为 0.30）
  n−1 层所有电子         0.85 （含该层的 d、f）
  n−2 及更内层所有电子   1.00

目标为 nd / nf 电子：
  同组其他电子           0.35
  位于其左侧的所有电子   1.00 （不再分 0.85）
```

`n*` 取值：`n=1→1.0  n=2→2.0  n=3→3.0  n=4→3.7  n=5→4.0  n=6→4.2`

`σ = Σ 贡献`，`Z* = Z − σ`，`E = −13.6 (Z*/n*)² eV`

### 完整例题：Fe（1s²2s²2p⁶3s²3p⁶3d⁶4s²）

```
对 3d（nd 类）：同组 3d 还有 5 个 ×0.35 = 1.75；左侧 3s²3p⁶、2s²2p⁶、1s² 共 18 个 ×1.00 = 18.00
   σ = 19.75，Z* = 26 − 19.75 = 6.25，E(3d) = −13.6×(6.25/3)² = −59.0 eV

对 4s（ns 类）：同组 4s 还有 1 个 ×0.35 = 0.35；n−1 层 3s²3p⁶3d⁶ = 14 个 ×0.85 = 11.90；
   更内 1s²2s²2p⁶ = 10 个 ×1.00 = 10.00
   σ = 22.25，Z* = 26 − 22.25 = 3.75，E(4s) = −13.6×(3.75/3.7)² = −14.0 eV
```

**必须知道的上限**：按上式计算 `E(3d) = −59.0 eV` 比 `E(4s) = −14.0 eV` 更低，而实验是 4s 先填。
所以 **Slater 法不能用来论证"4s 与 3d 谁先填"**，它只适合比较同 (n,l) 系列内的轨道能（如 Li、Be 各电离能）。
答题时若题目要求"与常见氧化态联系"（习题 2.19），按各步电离能递增、第四电离能突增来谈价电子数即可。

### 数量级自检

Li 第一电离能实验 5.392 eV、He 第一电离能 24.59 eV（习题 2.17、2.18 给的数据）。
如果算出来的电离能离这些数很远（比如差一个数量级），先查 `n*` 与"n−1 层是否误算 1.00"。

## 五、原子光谱项（本课最爱考的大题）

### 先分类：等价 vs 非等价

| | 定义 | 微观状态数 | 方法 |
|---|---|---|---|
| 非等价电子 | 至少一个量子数不同，如 (2p)(3p) | 各组态微观状态数相乘（6×6=36） | L、S 直接矢量加和，项全部组合都出现 |
| 等价电子 | n、l 都相同，如 (np)² | **组合数** `C(2(2l+1), k)` | 受 Pauli 限制，必须枚举后挑项 |

`p` 轨道 6 个状态、`d` 轨道 10 个状态：
`p² : C(6,2) = 15`　`d² : C(10,2) = 45`　`d³ : C(10,3) = 120`

### 微观状态数必须校验（这是过程分）

```
Σ_项 (2S+1)(2L+1) = 微观状态总数
```

校验样例：
- `p²`：¹D(5) + ³P(9) + ¹S(1) = 15 ✓
- `d²`：¹G(9) + ³F(21) + ¹D(5) + ³P(9) + ¹S(1) = 45 ✓
- `d³`：⁴F(28) + ⁴P(12) + ²H(22) + ²G(18) + ²F(14) + ²D(10) + ²D(10) + ²P(6) = 120 ✓

### 等价电子组态的推引步骤（以 d² 为例）

```
① 列出所有满足 Pauli 原理的 (m_l1, m_s1; m_l2, m_s2) 组合，共 45 个；
② 取 M_L = Σm_l、M_S = Σm_s；
③ M_S 的最大值 = 1 → 有 S=1 的项（三重项）；该组 M_L 最大为 3 → L=3 → ³F；
④ 从表中划掉 ³F 对应的 (2L+1)(2S+1)=21 个状态，重复 ③；
⑤ 依次得到 ¹G(9)、¹D(5)、³P(9)、¹S(1)；
⑥ 校验 21+9+5+9+1 = 45。
```
教材的表格法（表 2.6.4 对 (np)² 的 15 个微观状态逐行挑选）就是这一手法的原型。

### Hund 规则定基项（三步，方向不能错）

```
① S 最大者能量最低；
② S 相同时 L 最大者能量最低；
③ 再定 J：电子数 < 半满（未达半满）→ J = |L − S|；
            电子数 > 半满        → J = L + S；
            恰好半满（L=0）     → J = S，只有一个支项。
```

标准结果（直接用，考场上写出来即可）：

| 组态 | 基项（Hund 定） | 基支项 | 怎么来的 |
|---|---|---|---|
| d¹ | ²D | ²D₃/₂ | 未半满 J=\|L−S\|=2−½=3/2 |
| d² | **³F**（其余项 ¹G ¹D ³P ¹S） | ³F₂ | 未半满 J=3−1=2 |
| d³ | **⁴F**（其余项 ⁴P ²H ²G ²F ²D ²D ²P） | ⁴F₃/₂ | 未半满 J=3−3/2=3/2 |
| d⁵ | ⁶S（半满，L=0） | ⁶S₅/₂ | 半满 J=S=5/2 |
| d⁶（Fe²⁺、Fe³⁺ 的 3d⁶） | **⁵D** | **⁵D₄** | **过半满 J=L+S=4** |
| d⁹ | ²D | ²D₅/₂ | 过半满 J=2+½=5/2 |
| p² | **³P**（其余项 ¹D ¹S） | ³P₀ | 未半满 J=1−1=0 |

> 只列"考试要你写的那几项"：除 d²、d³、p² 外的组态，全项清单较长（d⁵ 就有 16 个项），
> 题目若问"全部光谱项"，用 `sc_spectroscopic_terms` 算，别凭记忆列。

真题对照：Fe 的 `[Ar]3d⁶4s²` 基谱项 = **⁵D₄**（小题第 4 题）；`Cu 的基谱项 ²S₁/₂`（第 3 题）。
`³D` 项：微观状态 15 个、`|L| = √6 ħ`、`|S| = √2 ħ`、`J = 3, 2, 1`（第 2 题原题）。

### 光谱选律（写"跃迁是否允许"时必须给）

```
ΔS = 0；ΔL = 0, ±1（L=0 → L'=0 禁）；ΔJ = 0, ±1（J=0 → J'=0 禁）；Δm_J = 0, ±1
```

## 六、波函数叠加态（真题第 13 题原样可复算）

题：`ψ = C₁ψ₂₁₀ + C₂ψ₃₁₁ + C₃ψ₃₁₀`（都已归一化，故 C₁²+C₂²+C₃²=1）

```
① 能量平均值 <E> = Σ|cᵢ|²Eᵢ = −C₁²/8 − (C₂²+C₃²)/18  (a.u.)  对应 −[…]/R (Rydberg)
   依据：E(n=2) = −1/(2·2²) = −1/8 a.u.；E(n=3) = −1/(2·3²) = −1/18 a.u.
② 能量为 −R/4 的概率 = C₁²      （−R/4 即 n=2 的能级）
③ 三个组分的 l 都是 1 → |L| = √(1·2)ħ = √2ħ 是确定值：均方根 = √2ħ，概率 = 1
④ <Lz> = C₁²·0 + C₂²·(1ħ) + C₃²·0 = C₂²ħ；Lz = ħ 的概率 = C₂²
```

**通式（背这三条就够）**

```
<E> = Σ |cᵢ|² Eᵢ        P(E = Eₖ) = Σ_{i: Eᵢ=Eₖ} |cᵢ|²
<Lz> = Σ |cᵢ|² mᵢ ħ      P(Lz = mħ) = Σ_{i: mᵢ=m} |cᵢ|²
<L²> = Σ |cᵢ|² lᵢ(lᵢ+1) ħ²   （l 全同则为确定值，非"平均"）
```

**陷阱**
- 漏 ħ（写成 `Σ|c|²m`）。
- 把"角动量值"答成 `ħ`（p 态是 `√2ħ`，不是 `ħ`）。
- 同一 n 的不同 (l,m) 能量相同，概率要**合并相加**再报。
- 能量单位：真题同时给 `a.u.` 与 `R` 两种写法，**两个都写更安全**。
