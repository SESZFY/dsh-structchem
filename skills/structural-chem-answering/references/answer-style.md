## 一、试卷结构（A 卷实测，决定你写多长）

```
一、选择填空(60 分)：  题号 1–15；其中第 6 题一张 10 行的点群表独占 (20 分) → 其余 14 题共 40 分，每题约 2~3 分
二、计算题(30 分)：    HMO（环烯丙基正离子）、K 的 A2 堆积+粉末衍射、一维势箱 —— 每题 10 分
三、回答问题(10 分)：  离子晶体点阵/空隙、富烯分子图与反应位点 —— 每题 5 分
```

由此得到的**篇幅纪律**：

- 2–3 分的小题（选择填空、表格）：**答案就是符号本身**，写解释不加分。
- 10 分的计算题：过程分是真的分——`①久期行列式 ②数值 ③图 ④结论` 四段必须齐。
- 5 分的回答题：一句话结论 + 必要标注，不写推导。

## 二、六条铁律（每条都有原文证据）

### 1. 能用一个符号答完的，不写第二个符号

> 试卷第 6 题表头：`分子 │ 点群熊夫里记号 │ 有无偶极矩 │ 有无旋光性`
> 答案行：`二氯甲烷CH2Cl2 │ C2v │ 有 │ 无`　`SF6 │ Oh │ 无 │ 无`

点群列全部是 **2–4 个字符**（`Td`、`Oh`、`Cs`、`Ci`、`C2v`、`D2h`、`D∞h`），性质列全部是 **1 个字**（`有`/`无`）。
实习一同一张表 29 行，写法完全一致（`H2O │ C2v │ 无 │ 有 │ 无`，多一列"有无对称中心"）。
→ **"有极性""略显极性""没有极性"这类写法一律视为未答。**

### 2. 一句结论，最多 22 字；用"因此"起

> 计算题第 1 题第 ④ 问全答案只有一句：`因此环烯丙基负离子的键长要长于环烯丙基正离子。`（22 字）

全文 `因此` 出现 2 次、`故` 0 次。→ 结论句用 `因此…` 或直接陈述比较关系 `A 的 X 大于 B`，不要写"综上所述""由此可见""经过分析可知"。

### 3. 数值必须带单位与方向，3 位有效数字

> `③ r=√3a/4 = 2.27Å`　`④ ρ=2M/(N_A·a³) =0.899g·cm-3`　`空间利用率为 58.9%`
> `sinθ1=0.208　θ1=12.0°　110`　`其键级为2.5`

实测单位写法（照抄）：

| 量 | 卷面写法 | 不要写 |
|---|---|---|
| 键长/晶胞参数 | `2.27Å`、`2.46 Å`、`133pm`、`1.42Å` | `2.27e-10 m` |
| 密度 | `0.899g·cm-3` | `899 kg/m3` |
| 空间利用率 | `58.9%`、`74.05%` | `0.589`、`58.9 percent` |
| 角度 | `12.0°`、`17.1°`、`120º`、`109°28′` | `12°`（少一位） |
| 能量（原子单位） | `–[C1²/8+(C2²+C3²)/18] a.u.`／同值 `–[…]R` | 只给 eV |
| 键级/电荷密度/自由价 | `2.5`、`0.667`、`0.398` | 带单位（它们无量纲） |

**位数的实测口径**：
- 计算得到的结果 → **3 位**：`2.27`、`0.899`、`58.9`、`12.0`、`0.667`、`0.398`、`0.208`。
- 中间量 → 保留 4 位：`0.1469*(h²+k²+l²)^0.5`。
- **教材表格里的常数照抄原位数**（不在考场重算）：`74.05%`、`68.02%`、`34.01%`、`90.69%`、`78.54%`、`1.155r`。
- 精确小数不截断：`键级 2.5`、`配位数比 8：4`、`占 1/4`、`占 1/2`、`正离子占 4/8`。

### 4. 作图题写"略"= 零分；用"见右图"

> `③ 见右图`（HMO 分子图）　
> `请画出110 面上离子的排布情况(要求表示出离子的接触情况)`（12 分题的一部分，必须画接触）
> `15. 氢原子处在ψ310 状态，请粗略地画以下波函数／电子云图形` → 答案是**三张图**：
> `径向密度函数R²n,l(r)~r 图 │ 角度分布图(Y~θ,φ) │ 电子云分布图(用点的疏密表示，要能明确看出角节面和径向节面)`

两份答案卷里独立出现的 `略` 次数 = **0**（唯一一处含"略"的字是题目里的"粗**略**地画"）。
→ **文字可省，图不可省，数值不可省，结论不可省。**
题目自己允许省过程时才省（`②指出富烯与亲电试剂发生反应的位置。(不要求计算过程)`）——"省过程"是题目的授权，不是你的选择。

### 5. 每个小问都要独立可判分：编号 + 换行

> ```
> ①久期行列式：…
> ② q1 = q2=q3 =2*1/3 = 0.667 … F1 = F2 = F3 =0.398
> ③ 见右图
> ④环烯丙基负离子基组态为… 因此…键长要长于…
> ```

答案卷的编号体系是 `① ② ③ ④`（计算题内）与 `1. 2. 3.`（大题内），**一问一行**，不合并成大段。
实习类填空则直接给结果：`①立方晶系，立方体心`　`②1 个，2 个`　`③…= 2.27Å`。

### 6. 计算题的过程式要写到"代入数字"这一步

> `⑤ 立方体心，h+k+l=奇数消光，因此前3 条谱线的衍射指标为110，200，211`
> `sinθ1=0.208　θ1=12.0°　110`

即：**判据（消光条件）→ 结论（衍射指标）→ 代入（sinθ 数值）→ 结果（θ 与指标）**，四样都在同一行体系里给全。
只写最终 θ 而不写消光条件，过程分丢掉一半。

## 四、该省的和不该省的

| 可以省 | 不可以省 |
|---|---|
| 题目明说"不要求计算过程"时的中间推导 | 结论句 |
| 重复前一小问已给出的组态/坐标（写"同上"即可） | 数值的单位 |
| 教材表格常数的推导（直接引数，如 74.05%） | 图（分子图/波函数/晶面排布） |
| 常识性名称解释（"点群""结构基元"不必下定义） | 每个小问的编号 |
| 单位换算的中间步骤（Å→pm 直接给换算后的数） | 判据链里的关键判据（如"h+k+l=奇数消光"） |

## 五、句式库（全部由答案原文结构抽出，可直接改写）

**点群判定（问理由时）**
```
该分子含 1 个 C2 轴和 2 个 σv，无 σh、无 i，故属 C2v 点群。
```

**偶极矩/旋光（问理由时）**
```
属 C2v 点群，偶极矩只能沿 C2 主轴，故有偶极矩；分子含 σv，故无旋光性。
```

**比较（键长/键级/稳定性）**
```
A 的键级大于 B，成键强，因此 A 的键长要短于 B。
```

**数值结论**
```
x²+x-2=0 → x=-2 或 x=1，故 E=α+2β 与 α-β。
```

**消光与指标**
```
立方体心，h+k+l=奇数消光，因此前 3 条谱线的衍射指标为 110，200，211。
```

**晶胞内容物**
```
负离子作立方简单堆积，正离子填入立方体空隙，占该类空隙的 1/2。
```

**谱学归属**
```
IR 活性只看振动模式的不可约表示是否与 x,y,z 相同：E1u、A2u 与 z 同表示，故只有它们红外活性。
```

**该省时**
```
见右图。 / 同上。 / 不要求计算过程，直接给出…（仅在题目这样要求时）
```
