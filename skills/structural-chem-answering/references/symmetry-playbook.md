# 分子对称性专册（点群 · 特征标表 · 振动 · 选律）

本册覆盖结构化学里点数最多、最"背多分"的一块。**判据有明确的树，不要凭感觉**；
表格数字一律以工具 `sc_character_table` / `sc_point_group` / `sc_normal_modes` 返回为准，
本册给的表用于手算时对照与考场默写。

## 一、点群判定树（照走，不停）

```
0. 是单个原子 / 球对称？ → 球群（教材题一般不考，按"任意转动"处理）
   │否
1. 是否直线形？
   ├ 是 → 有 i（对称中心）？  有 → D∞h（CO2, C2H2, N2）
   │                          无 → C∞v（CO, HCN, HCl）
   └ 否 ↓
2. 找最高轴次 Cn（n 最大者，n=1 表示无轴）
3. 是否存在 n 个垂直于主轴的 C2？
   ├ 有 → D 系
   │   ├ σh 存在？  → Dnh
   │   ├ n 个 σd 存在？→ Dnd
   │   └ 都没有 → Dn
   └ 无 → 继续
4. σh 存在？ → Cnh
5. n 个 σv 存在？→ Cnv
6. 只有 Cn → Cn（n=1 时看 7、8）
7. 只有 i → Ci；只有 σ → Cs；什么都没有 → C1
8. 有 S4/S6/S8 但无 σ、无 i、无 nC2⊥ → Sn（如 1,3,5,7-四甲基环辛四烯 S4）
9. 高对称（4 个 C3）：有 3C2 → T；有 σd → Td；有 i → Th
   更多（3 个 C4 / 4 个 C3 + i）→ Oh；只有真转动 → O
   5 重轴 → I（C60 类：有 i 或 σ → Ih）
```

**判定的五个易错点**

1. 最高轴次要找**最大**的，不是最先看到的（苯有 C6、6 个 C2、σh、i，取 C6 → D6h）。
2. "n 个垂直 C2" 必须数满 n 个；只找到 1 个 C2 的是 C 系，不是 D 系。
3. σh 与 σv/σd 的定义依赖主轴：**垂直于主轴的是 σh，含主轴的是 σv，含主轴且平分相邻 C2 的是 σd**。
4. 有 S2n 时不要急着写 S 群——S4 常与 D2d 混淆（见第二节）。
5. 记号大小写：主符号大写、轴次数字、下标小写（`C2v`、`D6h`、`Td`、`Oh`、`S4`、`Ci`、`Cs`）。

## 二、易混对辨析（这八组占错题的大半）

| A | B | 分辨判据 | 例 |
|---|---|---|---|
| **C2v** | **D2d** | D2d 有**两个互相垂直**的 C2（含主轴）与 2 个 σd，**无 σh**；C2v 只有 1 个 C2 + 2 个 σv | 顺式二氯乙烯 C2v ／ 丙二烯 CH2=C=CH2 D2d |
| **D2h** | **C2h** | D2h 有 3 个互相垂直的 C2 与 3 个 σ；C2h 只有 1 个 C2 + σh + i | 萘 D2h ／ 反式二氯乙烯 C2h |
| **D2h** | **D2d** | 都无 σh？错——D2h **有** i 与 σh；D2d 无 i、无 σh，只有 S4 | 联苯(0°) D2h ／ 联苯(90°) D2d |
| **Td** | **Oh** | Td：4C3 + 3S4，**无 C4、无 i**；Oh：3C4 + i + 6C2 | CH4 Td ／ SF6 Oh |
| **D3h** | **C3h** | D3h 有 3 个 ⊥C2；C3h 只有一个 C3 + σh，无 C2 | BF3 D3h ／（C3h 罕见） |
| **D3d** | **C3v** | D3d 有 i（n 为奇数时）与 S6；C3v 有 3 个 σv、无 i | 椅式环己烷 D3d ／ 船式环己烷 C2v |
| **S4** | **D2d** | S4 只有 S4 + C2，**无 ⊥C2**；D2d 有 2 个 ⊥C2 与 2 个 σd | 四甲基环辛四烯 S4 ／ 丙二烯 D2d |
| **Cs** | **C2v** | Cs 只有一个镜面；C2v 有 C2 + 2 个 σv | 溴代吡啶 Cs ／ 二氯甲烷 C2v |

**口诀（只在判完树之后用来复核）**：`有 i 则必无 μ`；`有 σ/i/Sn 则必无旋光`；
`D 系无 μ`（除了 D 系里没有 σ 与 i 的 Dn——但它仍无 μ，因为 μ 只能落在 Cn/Cnv/Cs/C1）。

## 三、三张必背清单（南开实习一的答案原文）

```
有对称中心：C2h, C4h, C6h, D2h, D4h, D6h, D3d, D5d, Th, Oh
具有偶极矩：C1, C2, C3, C4, C5, C6, C2v, C3v, C4v, C5v, C6v
具有旋光性：C1, C2, C3, C4, C5, C6, D2, D3, D4, D5, D6, T, O
```

**可推导的补充（考试同样给分，比死记安全）**

- 有 i 的完整集合：`Ci(=S2)`、`C2h/C4h/C6h…`（**n 为偶数**的 Cnh）、`S6(=C3i)`、`D2h/D4h/D6h…`、`D3d/D5d`（**n 为奇数**的 Dnd）、`Th`、`Oh`、`D∞h`、`Ih`。
  → `D2d、D4d` **没有** i；`C3h` **没有** i（n 为奇数）。
- 有偶极矩的完整集合：`C1`、`Cs`、`Cn`、`Cnv`、`C∞v`。
  （A 卷里 `溴代吡啶 Cs 有`、`CO C∞v 有`，正是这两类。）
- 有旋光性的完整集合：**全部由真转动构成的第一类点群** —— `Cn`、`Dn`、`T`、`O`、`I`。
  → `S4` 有 S4 这种第二类操作，**必然无旋光**（这是它常被错判的一处）。

> **教材附录的 Oh 表常用另一种类顺序**：`E, 8C3, 6C2, 6C4, 3C2, i, 6S4, 8S6, 3σh, 6σd`
> （即把 6C2 与 3C2 换位、6S4 与 8S6 换位）。同一个不可约表示的**同一行数字会整体换位**。
> 抄表时对齐的应该是**类**，不是位置：报 `chars` 给工具前，先看工具回执里的 `classes` 是什么顺序，
> 按那个顺序排。混用两种顺序会得到一堆小数，这是"约化出来不是整数"的头号原因。

**自查法（写完任何一行都能验）**：`Σ_c g_c·χ² = h`。例如 Oh 的 T1u：`1·9 + 6·1 + 6·1 + 3·1 + 1·9 + 6·1 + 3·1 + 6·1 = 48` ✓。
**第二道自查（只要点群里有全对称表示就成立）**：任何非全对称的不可约表示都必须满足 `Σ_c g_c·χ(c) = 0`
（它要与 A1/A1g 正交）。这条能抓出单格抄错——某一行加总不为零，一定是那一行有数字错。

### 怎么用"基函数"列答题

- `x, y, z` 所在的表示 → **IR 活性**的表示。
- `Rx, Ry, Rz` 所在的表示 → 转动自由度（从 Γ_3N 里减掉）。
- 二次函数（`x², y², z², xy, xz, yz, x²−y²`）所在的表示 → **Raman 活性**的表示。
- 题问"某基函数属哪个不可约表示" → 直接读该列。

## 五、约化公式与实例

`n_i = (1/h) Σ_c g_c · χ_i(c) · χ_Γ(c)`

其中 `g_c` 是该类的操作个数（`E` 为 1，`2C3` 为 2，`3σv` 为 3）。

**实例：H2O 的 Γ_3N（C2v，h=4，类序 E, C2, σv(xz), σv'(yz)）**

| 操作 | 不动原子数 | χ = n_不动 × χ(x,y,z) |
|---|---|---|
| E | 3 | 3 × 3 = **9** |
| C2 | 1（O） | 1 × (−1) = **−1** |
| σv(xz) | 3（分子在 xz 面内） | 3 × 1 = **3** |
| σv'(yz) | 1（O） | 1 × 1 = **1** |

```
n(A1) = ¼[9·1 + (−1)·1 + 3·1 + 1·1] = 12/4 = 3
n(A2) = ¼[9·1 + (−1)·1 + 3·(−1) + 1·(−1)] = 4/4 = 1
n(B1) = ¼[9·1 + (−1)·(−1) + 3·1 + 1·(−1)] = 12/4 = 3
n(B2) = ¼[9·1 + (−1)·(−1) + 3·(−1) + 1·1] = 8/4 = 2
Γ_3N = 3A1 + A2 + 3B1 + 2B2      校验 3+1+6+4 = 9 ✓
```
减平动（A1+B1+B2）与转动（A2+B1+B2）→ **Γ_vib = 2A1 + B1**。
C2v 里 x,y,z 分别为 B1、B2、A1，二次函数覆盖 A1/A2/B1/B2 → **2A1 与 B1 既 IR 活性又 Raman 活性**。

> 算这一格时最容易出的错：把 `B1` 算成 2、`B2` 算成 3（我核稿时就犯过一次）。
> 自检只有一条：**四行加起来必须等于 3N = 9**，而且减完平动转动后剩下的必须是 `2A1 + B1`
> ——若减出 `2A1 + B2`，说明 B1/B2 两行换了位，回去重算 `1·(±1)` 的符号。

**单原子位移的 χ(x,y,z) 速查**

| 操作 | χ(x,y,z) |
|---|---|
| E | 3 |
| Cn(θ) | `1 + 2cosθ`（C2=−1，C3=0，C4=1，C6=2） |
| i | −3 |
| σ | 1 |
| Sn(θ) | `−1 + 2cosθ`（S4=−1，S6=0） |

## 六、3N 分解流程（写进答题纸的固定五步）

```
① Γ_3N：按类求 χ = (不动原子数) × χ(x,y,z)
② 约化：n_i = (1/h)Σ g_c χ_i χ_Γ，逐项代入并校验 Σ n_i·dim_i = 3N
③ 减平动 Γ_trans = x,y,z 的表示
④ 减转动 Γ_rot = Rx,Ry,Rz 的表示（线性分子只减 2 个转动）
⑤ Γ_vib = Γ_3N − Γ_trans − Γ_rot → 列 IR 活性 / Raman 活性 / 静默
```

- **线性分子自由度 3N−5**（CO2 → 4 个振动；C2H2 → 7 个）。
- 有对称中心（i）的分子：**IR 与 Raman 互斥**（同一模式不可能同时活性）。
- C2v、Cs、C1 这类无 i 的低对称点群：多数模式双重活性，但**仍要逐表示对照**。

**两个校验样例**

| 分子 | 点群 | Γ_vib | 说明 |
|---|---|---|---|
| H2O | C2v | `2A1 + B1` | 3 个振动：对称伸缩、弯曲（A1）、反对称伸缩（B1） |
| SF6 | Oh | `A1g + Eg + 2T1u + T2g + T2u` | 15 个振动；只有 T1u 是 IR 活性（与 x,y,z 同表示），A1g/Eg/T2g Raman 活性，T2u 静默 |

## 七、选律三条（一句话版）

1. **IR 活性**：振动模式的不可约表示与 `x`、`y`、`z` 中任一个相同。
2. **Raman 活性**：与二次函数（`x², y², z², xy, xz, yz, x²−y²`）中任一个相同。
3. **互斥规则**：分子有对称中心 `i` 时，同一模式不可能同时 IR 与 Raman 活性。

配套判断（卷面表格题直接用）：

| 判据 | 结论 | 依据 |
|---|---|---|
| 有 `i` | 必无偶极矩 | 反演使偶极矢量反向，只有零矢量不变 |
| 属 `Cn`/`Cnv` | 有偶极矩，**沿主轴** | 主轴是唯一不变方向 |
| 属 `Cs` | 有偶极矩，**在镜面内** | 镜面内矢量不变 |
| 属 `C1` | 可能有偶极矩（任意方向） | 无约束 |
| 属 `D`/`T`/`O`/`I` 系 | 无偶极矩 | 至少有两个不平行的 Cn 或高对称使矢量和为零 |
| 点群全为真转动（`Cn`/`Dn`/`T`/`O`/`I`） | 可能有旋光性 | 无第二类操作 ⇒ 与其镜像不重合 |
| 有 `σ`、`i`、`Sn` 中任一个 | 必无旋光性 | 第二类操作使其与镜像可重合 |
