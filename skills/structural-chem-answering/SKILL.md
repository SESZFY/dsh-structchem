# 结构化学答题（周公度体系 · 南开真题口径）

这套方法是从**南开结构化学试卷答案（5 页）+ 模型实习答案（8 页）+ 教材第 1–3 章习题**里反推的，
不是通用化学常识。它管的是**"怎么写才算标准答案"**，不只是"答案对不对"。

## 一句话总纲

> 结构化学的答案 = **一个正确的符号 / 一个带单位的数 / 一张图**，加 **不超过一句的判据**。
> 判据只解释"为什么是这个符号"，不重讲课本。

实测依据（全部来自答案卷原文，详见 `references/answer-style.md`）：

- 点群表的三格答案是 `C2v` / `有` / `无`——**2–3 个字符**，没有一句话。
- 数值答案是 `2.27Å`、`0.899g·cm-3`、`58.9%`、`θ1=12.0°`——**3 位有效数字 + 单位**。
- 计算题的"结论"只有一句：`因此环烯丙基负离子的键长要长于环烯丙基正离子。`（**22 字**，全卷最长解释句）。
- 画图指令 `请画出110 面上离子的排布情况(要求表示出离子的接触情况)` 占分，**写"略"= 零分**。

| 用 | 不用 |

## 开工流程（五步，一步都别跳）

### 第 1 步：读题定性 —— 先把"要答几个空"数清楚

题干动词直接决定题型，题型决定工具，工具决定格式。**先数空，再做题**：

- `给出下列分子所属点群，判断有无偶极矩和旋光性` → 每行是**三个独立得分点**，漏一格扣一格。
- `写出…Schrödinger 方程` → 纯符号题，不调工具，注意**核间距项与电子互斥项**。
- `计算 / 求 / 估算` → 必须给过程式 + 数值 + 单位，答案不写单位直接扣。
- `画出 / 作图 / 粗略地画` → 必画。"见右图"可以，"略"不行。
- `试比较 / 试问…何种 / 为什么 / 说明` → 一句话判据，不要展开成段落。

### 第 2 步：定工具 —— 一道题经常要连调 2–3 个

| 题目要的东西 | 先调 |
|---|---|
| 点群 + 偶极矩 + 旋光性（一张表） | `sc_point_group` → `sc_selection_rules` |
| 3N 振动分解 + IR/Raman 活性 | `sc_point_group`（拿点群）→ `sc_normal_modes` |
| 某个不可约表示的分解 | `sc_reduce_representation`（`chars` 按该点群类的顺序给） |
| 查基函数属于哪个不可约表示 | `sc_character_table`（看 `basis` 字段） |
| HMO 分子图 | `sc_huckel` → 直接拿 `bond_orders` / `charge_densities` / `free_valence` |
| 晶体：晶系 + 晶面 + 堆积 + 空隙 | `sc_unit_cell` → `sc_miller_indices` → `sc_packing` |
| 晶体场 + 自旋态 + 磁矩 | `sc_crystal_field`（给 `d_n`、`geometry`、配体） |
| 不知道该写什么骨架 | `sc_answer_card("点群")` 拿答题卡；`sc_rationale("偶极矩")` 拿判据句 |

### 第 3 步：算 —— 能算的一律不准心算

- 数值只承认两类来源：**工具返回的 `value` + `steps`**，或题目直接给的数。
- 工具的 `steps` 就是给你抄进答题纸的逐步算式（含中文与代入数字），**按原样落笔**。
- 报错就停：`ok=False` 说明输入缺东西（少原子、少匝数、点群符号写错），按 `error` 补输入，**不要自己凑一个能跑的输入**——那算的已不是同一道题。
- 单位：长度 **pm / Å**、能量 **eV / a.u. / cm⁻¹**、角度 **°**。教材与真题混用 pm 与 Å（`2.27Å`、`133pm`），**同一题内统一**，跨题各自照原样。

### 第 4 步：落笔格式 —— 看菜下饭

| 题型 | 格式 | 例子 |
|---|---|---|
| 选择填空 | 只写答案，选择题写括号里的字母 | `( D )` / `( A )` |
| 表格题（点群/性质） | 每格只填符号或"有/无" | `C2v │ 有 │ 无` |
| 计算题 | 分步编号 ①②③④，每步一行式子 | `①久期行列式：… ②q1=q2=q3=0.667` |
| 作图 | 必须出图，并标注节面/接触情况/坐标轴 | `见右图` |
| 解释 | 一句判据，结论先行 | `因此…` / `故…` |
| 比较 | 一句结论 + 一个可命名原因 | `X 的键长要长于 Y` |

### 第 5 步：交卷自检（30 秒过一遍）

- [ ] 每个"空"都填了吗（点群、偶极矩、旋光性是三个空）？
- [ ] 点群用的是**熊夫利记号**（`C2v`，不是 `mm2`）？题干若问国际记号再写 `mm2`。
- [ ] 数值 3 位有效数字 + 单位？角度带 `°`？
- [ ] 要画的图给了吗（波函数/电子云/分子图/晶面排布）？
- [ ] 有没有把"有/无"写成"有一定极性"这类模糊话？
- [ ] 判据句 ≤ 1 句、≤ 30 字？
- [ ] 线性分子用 3N−5 而不是 3N−6 了吗？
- [ ] **上下标整份统一吗**（全富文本 `C₂v` / 全平排 `C2v`，不混用）？光谱项多重度在左上、L 大写、J 在右下？
- [ ] **同一个字母在本题只有一个含义吗**？重点查 `σ χ μ ν Δ α β Z φ` 这九个——每个都至少两种意思，见 `references/notation-and-typography.md` 的消歧表，或直接 `sc_notation("μ")` 查。

## 每类题的作答范式：这样写满分 / 这样写失分

### 1. 点群 + 偶极矩 + 旋光性（表格式，2 分/行）

```
分  子        点群熊夫里记号   有无偶极矩   有无旋光性
二氯甲烷CH2Cl2      C2v            有            无
SF6                 Oh             无            无
丙二烯CH2=C=CH2     D2d            无            无
H2O2                C2             有            有
```
**满分**：三格全填、点群用熊夫利记号、偶极矩只写"有/无"。
**失分**：`C2V`（大小写错）· `mm2`（写成国际记号）· `D2h`（丙二烯判错）· 偶极矩格子写"有一定极性"。
判据链要在草稿上走完，**卷面只写结果**（题干没问理由时）。

### 2. 点群判定（要理由时）

满分：
```
该分子含 1 个 C2 轴与 2 个通过 C2 的 σv 镜面，无 σh、无 i，故属 C2v 点群。
```
失分：
```
该分子不对称，属 C2v。            ← 判据链缺失
因为分子有对称面所以是 C2v。       ← 只说了一个条件
```
理由只写"最高轴次 → 有无 nC2⊥ → 有无 σh/σd"，一条链，不解释什么叫点群。

### 3. 数值计算（HMO / 晶体场 / 势箱）

满分（照南开卷格式）：
```
①久期行列式： |x 1 1|
              |1 x 1| = 0
              |1 1 x|
   x²+x-2=0, x=-2 或 x=1
   E1=α+2β, E2=E3=α-β
② q1=q2=q3=0.667   P12=P23=P31=0.667   F1=F2=F3=0.398
③ 见右图（分子图：q 标在原子旁，P 标在键上，F 用箭头指原子）
④ 环烯丙基负离子的键长要长于环烯丙基正离子。
```
**满分要素**：行列式给出来 → x 解出来 → 能级带 α、β → 数值 3 位 → 分子图真的画 → 比较题一句话结论。
**失分**：只给最终数值不给行列式（过程分没了）· 能级写成 `α+2`（丢 β）· 分子图写"略"· 比较题写三段推导。

### 4. 晶体结构四连问（点阵型式 / 基元 / 空隙 / 利用率）

满分（照南开 Q12 格式，逐空对应）：
```
AO2 晶体属 立方面心 点阵型式；一个晶胞中有 4 个结构基元；
一个结构基元的内容为 1 个 Zr4+、2 个 O2-；一个晶胞中有 8 个 O2-；
正负离子配位数比为 8:4；O2- 作 立方简单 堆积；
A4+ 填入 立方体 空隙；占该类空隙的 1/2。空间利用率 58.9%。
```
**满分要素**：每问只答一个词/一个数；百分比 3 位；"点阵型式"与"结构基元"分别答（不是一个东西）。
**失分**：把"立方面心"写成"面心立方堆积"（点阵型式 ≠ 堆积型式）· 结构基元数写成 8（把 O²⁻ 数当基元数）· 利用率写 0.589 不写 %。

### 5. 光谱项推导

满分：
```
d² 组态：等价电子，微观状态数 C(10,2)=45。
光谱项：1G(9) 3F(21) 1D(5) 3P(9) 1S(1)，合计 45，校验通过。
按 Hund 规则，S 最大者（3F、3P）最稳定；其中 3F 的 L 最大，故基项为 3F。
d² 未过半满，J=|L-S|=2，基支项为 3F2。
```
**满分要素**：等价/非等价说清楚 → 微观状态数**校验** → Hund 三规则走完 → 基支项 J 由"半满前/后"定。
**失分**：等价电子与非同科电子混用组合数 · 不校验 45 · Fe 3d⁶ 忘"过半满 → J=L+S=4"（基支项写成 5D0）。

### 6. IR / Raman 选律

满分：
```
Γ_3N = 3A1 + A2 + 3B1 + 2B2（9 个自由度，校验 3+1+6+4=9）
减平动(A1+B1+B2)与转动(A2+B1+B2)得 Γ_vib = 2A1 + B1。
H2O 属 C2v，x,y,z 分别属 B1,B2,A1，二次函数属 A1/B1/B2/A2，故 2A1 与 B1 全部 IR 活性且 Raman 活性。
```
失分：Γ_3N 不减平动转动 · 写"因为 C2v 没有对称中心所以都活性"（C2v 本来就没有 i，这条理由不成立）· 把 Raman 判据写成 x,y,z · **B1/B2 两行算错（正常结果必须是 2A1+B1；若减出 2A1+B2 说明 B1/B2 换了位）**。

### 7. 双原子分子 MO

满分：
```
O2（16 个价电子）：(σ2s)²(σ*2s)²(σ2pz)²(π2p)⁴(π*2p)²
键级 = (8−4)/2 = 2；π* 有 2 个单电子，故为顺磁性。
```
失分：能级顺序写反（**N2 及更轻 σ2p 在 π 之上，O2/F2 反之**）· 键级忘除 2 · 忘写"顺磁/抗磁"。

### 8. 势箱 / 共轭分子吸收波长

满分：
```
E_n = n²h²/8mL²，丁二烯 4 个 π 电子占 n=1,2；HOMO→LUMO 为 n=2→3：
ΔE = (3²−2²)h²/8mL² = 5h²/8mL²，λ = hc/ΔE。
```
失分：忘 n²（写成 n）· L 用 nm 与 pm 混算 · 共轭分子忘"势箱长度 = 共轭链长 + 两端延伸"。

### 9. 作图题（波函数 / 电子云 / 分子图 / 晶面排布）

满分（ψ310 为例，照南开 Q15）：
```
R²₃₁(r)~r：一个径向节面（n−l−1=1），原点为零，峰在核外；
Y(θ)~θ：pz 型双球，一个角节面（l=1）；
电子云点图：用点的疏密表示，标出角节面（平面）与径向节面（球面）。
```
失分：只画一张图（题目要三张）· 电子云用"阴影满涂"代替点密度 · 不标±号 · 不标节面。

### 10. 解释"为什么"

满分：
```
苯的 IR 活性的振动只有 E1u 与 A2u（与 z 同表示），因为活性判断看振动模式的不可约表示是否与 x,y,z 相同。
```
失分：`因为它有红外吸收所以是红外活性`（循环论证）· 解释题写 4 行推导 · 引入"偶极矩变化"却不指哪个表示。

### 11. 晶体场 / 磁性

满分：
```
Fe²⁺（d⁶），八面体弱场：t2g⁴eg²，4 个单电子，
μ = √(4×6) = 4.90 BM，高自旋（Δo < P）。
CFSE = (−0.4×4 + 0.6×2)Dq = −0.4Dq。
```
失分：`t2g⁶eg⁰` 与弱场混搭（高低自旋混着写）· μ 用 n+2 · CFSE 符号反 · 忘写"高/低自旋"。

### 12. 晶面指标 / 面间距 / 衍射

满分：
```
截 x=a/2, y=b/3, z=c/4 → 倒数 2,3,4 → 互质 → (234)。
立方晶系：d(234)=a/√(2²+3²+4²)=a/√29；2dsinθ=λ → θ。
```
失分：忘取倒数 · 写成 (432)（顺序必须对 x,y,z）· 负指数画成普通数字（要写 1̄ 或 −1）。

### 13. 写 Schrödinger 方程

满分（H₂，原子单位）：
```
Ĥψ = Eψ
Ĥ = −½∇₁² − ½∇₂² − 1/r_a1 − 1/r_b1 − 1/r_a2 − 1/r_b2 + 1/r₁₂ + 1/R
```
失分：漏 `+1/R`（核互斥）· 漏 `+1/r₁₂`（电子互斥）· 吸引项写成正号 · 一半 SI 一半原子单位。
判分就看**项数对不对**（H₂ 共 8 项）与**符号对不对**，不看你会不会解。

### 14. 谱学题（光电子能谱 / XPS）

满分：
```
Ar 的第一条谱线分裂为强度比 2:1 的两个峰，由 (l+1):l = 2:1 得 l=1，故被电离的是 3p 电子。
```
失分：`因为分裂成两个峰所以是 p 轨道`（没给比与公式）· 把"结合能 = 轨道能量"写成正号（应为负值）·
XPS 化学位移说成"氧化态越高结合能越小"（反了）· 说"成键电子电离后谱带更窄"（实际更宽）。

### 15. VSEPR / 构型 / 杂化

满分：
```
SF4：中心 S 的价层电子对数 = 4 + 1 = 5（AX4E），电子对构型为三角双锥，
去掉孤对后分子构型为跷跷板，点群 C2v，键角小于理想值。
```
失分：`SF4 是四面体`（错，跷跷板）· 只写杂化 `sp3d` 不写构型 · 把电子对构型当分子构型（AX3E2 答三角双锥，应 T 形）。

### 16. 晶面指标与粉末衍射

满分（bcc K，a=5.247 Å，λ=1.542 Å）：
```
立方体心，h+k+l 为奇数消光，因此前 3 条谱线的衍射指标为 110，200，211。
sinθ = (λ/2a)√(h²+k²+l²) = 0.1469√(h²+k²+l²)
sinθ₁=0.208 → θ₁=12.0°（110）；sinθ₂=0.294 → θ₂=17.1°（200）；sinθ₃=0.360 → θ₃=21.1°（211）
```
失分：先算角度后补消光条件（顺序丢过程分）· 体心当成无消光 · θ 只留整数位 · 指标与角度不配对 · 把 2θ 当 θ。

## 常见陷阱清单（结构化学特有，33 条）

**对称性**
1. 丙二烯、联苯（二面角 90°）、1,3,5,7-四甲基环辛四烯：**D2d 不是 D2h**——它们没有 σh，也没有 i。
2. 顺式二氯乙烯（C2v）与丙二烯（D2d）是不同判据：C2v 只有**一个** C2；D2d 有**两个互相垂直**的 C2 外加 2 个 σd。
3. `C2V` / `d6h` 大小写错一律扣；点群符号是 `C2v`、`D6h`、`Td`、`Oh`、`S4`、`Ci`、`Cs`。
4. Td 与 Oh 的差别不在"立不立方"：Td 有 4C3 与 3S4、无 C4；Oh 有 3C4 与 i。
5. D3h 与 C3h 差在 3 个 ⊥C2；椅式环己烷是 **D3d**（有 i 与 S6），船式是 C2v。
6. 把"有对称中心"当成判断旋光的唯一条件：真正判据是**无 i 且无 σ**（C1、Cn、Dn、T、O 系列）。

**群论 / 振动**
7. 3N 分解忘了减平动与转动；**线性分子是 3N−5**（CO2 4 个、C2H2 7 个）。
8. IR 判据写成"二次函数"、Raman 判据写成"x,y,z"——两者写反是本课最常见失分。
9. 有对称中心的分子忘**互斥规则**，答出"某模式 IR 与 Raman 同时活性"。
10. 约化时 `chars` 顺序与该点群类的顺序不一致（E、C2、σv 的排列各表不同），算出来全是小数。
11. 约化的 `n_i` 加起来不等于 3N——说明 χ 取错或类数对不上，回头核。

**量子化学**
12. 势箱能量漏 n²；`E=9h²/8mL²` 写成 `h²/8mL²`。
13. 类氢节面：径向 `n−l−1`、角节面 `l`、总 `n−1`；三个数别互换。
14. "概率密度最大处"≠"最可几半径"（后者是 `r²R²` 极大）——题目问哪个就答哪个。
15. Slater：同组 0.35（1s 同组 0.30）；n−1 层 **0.85**（含该层的 d）；更内层 1.00；**d/f 电子左侧一律 1.00**。
16. 拿 Slater 算出的 4s、3d 能量去论证"4s 先填"——Slater 法在这一比较上是失效的，教材明确写了。
17. 等价电子用"可区分组合"去数微观状态（d² 应为 C(10,2)=45，不是 100）。
18. Hund 第三规则方向反：**半满前 J=|L−S|，过半满 J=L+S**（Fe 3d⁶ → ⁵D₄，不是 ⁵D₀）。
19. 光谱项符号上下标丢：`3F` 要写成 `³F`；基支项 `⁵D₄` 的下标 4 不能省。

**分子轨道**
20. 双原子分子能级顺序：**N2 及更轻 σ2p 在 π 之上；O2、F2 反过来**。写反 = 整张 MO 图作废。
21. 键级忘除以 2；或把"单电子数"当成"键级"。
22. HMO 自由价只减**与 r 直接相连**的键级；把环上全部键级加进去必错（环丙烯 F=0.398，不是 0）。
23. 芳香性只查 4n+2，不看"平面 + 环状 + 全共轭"；环辛四烯（8π，盆形）非芳香。
24. 电荷密度写成 1（未乘占据数 n_i）或忘 `q_r=Σn_i c_ir²`。

**晶体**
25. 晶面指标忘取倒数，或 (234) 顺序按 y,x,z 写成 (432)；负指数要画横线/写负号。
26. "点阵型式"与"堆积型式"混答：点阵型式答 `立方面心`，堆积型式答 `A1/ccp`。
27. "结构基元"与"晶胞内原子数"混答：金刚石 8 原子/胞、4 个结构基元、**1 个基元 = 2 个 C**。
28. 空间利用率忘乘晶胞内原子数。半径比题的三个固定陷阱：① **拿键长当 r₋**（KBr 真题：328 pm 是键长，`r₋=328−133=195`，比值 0.682 → 八面体；误用 133/328=0.405 会掉进四面体档，选错成 B）；② **比错对象**（`r₊/r₋` 还是 `r₋/r₊` 看清谁大，分子永远是较小的阳离子）；③ **临界值归属含糊**——取左闭右开，临界值归配位数更大的一档：0.225→四面体、0.414→八面体、0.732→立方体。

**配位 / 谱学**
29. 高自旋写 t2g⁶ 这类"低自旋组态 + 高自旋标签"混搭；`μ=√(n(n+2))` 写成 n+2。
30. CFSE 符号：八面体 `(−0.4 n_t2g + 0.6 n_eg)Dq`，符号颠倒会让"稳定性排序"整题反。
31. XPS 化学位移方向说反：**氧化态越高，内层电子结合能越大**。
32. 把有机化学的 ¹H 位移经验区间套到结构化学题（本课只考选律、等价性、谱带形状）。
33. 作图题写"略"——图就是分，且要标节面、±号、接触情况、坐标轴。

## 自检句库（用最终结果反查中间过程）

这几句是**校对工具**，不是知识。写完一题，挑对应的那条念一遍，能挡住大部分抄错。

| 题型 | 自检句 | 对不上说明 |
|---|---|---|
| 振动分解（C2v 分子，3 原子） | 减完平动转动必须得 `2A1 + B1` | 得到 `2A1 + B2` → B1/B2 两行算反了 |
| 任何约化 | `Σ n_i × dim_i` 必须等于 3N（或该体系总自由度） | 对不上 → χ 取错或类顺序错 |
| 点群 + 三性质 | 有 i 的分子，"偶极矩"与"旋光性"两格必须都是"无" | 出现"有" → 点群判错 |
| 点群 + 三性质 | 旋光性为"有"的分子，点群里不能出现 σ、i、S | 出现了 → 点群或旋光列错 |
| 光谱项 | `Σ(2S+1)(2L+1)` 必须等于微观状态总数（d² = 45） | 不等 → 漏项或把等价当非等价 |
| 光谱项 | 基支项 J：半满前取 `|L−S|`，过半满取 `L+S` | 3d⁶ 写成 ⁵D₀ → 方向反了 |
| 双原子 MO | 键级 = (成键 − 反键)/2，且 N₂ = 3、O₂ = 2 | 得 6 或 4 → 忘除 2 |
| HMO | `Σ q_r` 必须等于 π 电子总数 | 不等 → 占据数或系数平方漏乘 |
| HMO | 自由价只能减**相邻**键级；苯/环丙烯的 F≈0.398 | 得负数 → 把不相邻键级也减了 |
| 空间利用率 | A1/A3 应得 74.05%、A2 68.02%、A4 34.01% | 得 18% → 忘乘 Z |
| 半径比 | 先减出 r₋：`d = r₊ + r₋`；KBr 应得 0.682→八面体 | 得 0.405 → 把键长当 r₋ 了 |
| 晶体场 | 组态与自旋标签必须自洽（t2g⁶ 不能标"高自旋"） | 矛盾 → 重判 Δo 与 P |
| 晶体场 | μ 表：4 个单电子 = 4.90 BM | 得 4.47 → 用了 n+2 而不是 √(n(n+2)) |
| 叠加态 | `Σ|cᵢ|² = 1`；同一能量的概率要合并 | 概率和 ≠ 1 → 漏合并或忘平方 |
| 写方程 | 项数：H₂ 共 8 项（2 动能 + 4 吸引 + 1 电子互斥 + 1 核互斥） | 7 项 → 漏核互斥 |

| 缺什么 | 处理 |
|---|---|
| 点群题给的是分子图/照片但你读不出取代基位置 | 明确说"缺哪个基团的位置"，只对能确定的骨架给点群，**不要猜一个分子继续算** |
| 晶体题缺晶胞图或分数坐标 | 只答能由文字确定的（晶系、指标），其余注明"需晶胞图" |
| 计算题缺数值（如没给键长/半径） | 保留符号式作答，并说明"代入给定数值即得" |
| 配位场题没给成对能 P | 按配体强弱与中心离子周期定性判高/低自旋，并注明"若给出 P 需与 Δo 比较" |
| 光谱项题只给"某组态"但没说是哪种元素 | 按组态算（如 d²），不要假设具体元素（Fe 的 3d⁶ 与一般的 d⁶ 同项、不同基支项要看半满） |

## 分值 · 时间 · 字数（按南开卷结构）

| 题型 | 分值 | 建议用时 | 答案长度 |
|---|---|---|---|
| 选择填空一格 | 2–3 | 1 min | 一个符号/一个数 |
| 点群表格一行（点群+偶极矩+旋光性） | 2 | 20 s | 2–3 字符 |
| 计算题 | 10 | 12–15 min | 四段式，20 行以内 |
| 回答问题 | 5 | 5 min | 2 行以内 |
| 作图题 | 5–10 | 6–10 min | 图 + 标注 |

**字数硬上限**：解释类 ≤ 40 字，比较类 ≤ 22 字，纯填空 ≤ 3 字符。
超了不是"更完整"，是**在替老师重讲教材**——阅卷只找判据词。

## 交付纪律

- 用户要**答案**：直接给标准答案形态（符号/数值/图 + 一句判据），不要先讲题型分析。
- 用户要**为什么**：一句判据（可附一行补充），不要展开成教案。
- 用户要**批改**：先指出失分点（对照上面 33 条陷阱），再给标准写法。
- 用户要**学思路**：按"判题型 → 定工具 → 算 → 格式 → 自检"五步讲，示例必须来自南开卷或教材习题。
- 题干里的结构/晶胞图读不出来时，**明确说缺哪个结构**，不要凭空补一个分子继续推——那算出的点群与题目无关。
