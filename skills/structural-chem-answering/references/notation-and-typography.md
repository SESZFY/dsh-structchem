# 符号与排版规范

> 结构化学答案的失分有两类：一类是算错，一类是**写出来的东西不是那个东西**。
> 后者更冤——σ 有四个意思、μ 有三个、Z 有两个，同一个字母换个位置就是另一道题。
> 这份规范管的就是后者。
>
> 全部结论都来自三份真实语料的字符级统计（`tools/audit_notation.py` 可复跑）：
> 《结构化学基础》第 5 版教材 OCR 88 页 + 南开结构化学真题与实习答案 + 《结构化学题库》1681 题标准答案。
> 凡引用「语料 N 次」都是该脚本的真实计数，不是印象。

## 总纲

**符号规范的目标是消歧，不是好看。**

写答案时只问一句：**这个符号在本题里承担哪一个含义，我有没有让它唯一？**
如果同一题里 Z 既指核电荷又指晶胞式量数、φ 既指方位角又指键角，那答案即使数值全对也读不通。

---

## 一、上下标：双轨制，但**一份答案只走一轨**

教材原版是富文本（OCR 里能看到 `³P₀`、`d⁶ → t₂g⁶e_g⁰`），但 PDF 提取时大量塌成平排。语料计数：

| 写法 | 富文本 | 平排 |
|---|---|---|
| 点群 | `C₂v` 93 | `C2v` 521 |
| 光谱项 | `³F₂` 5 | `3F2` 114 |
| d 轨道 | `t₂g/e_g` 4 | `t2g/eg` 55 |
| 波函数 | `ψ₂₁₀` 3 | `ψ210` 10 |

**平排多，是提取 artifacts，不是教材写法。** 所以规范是：

- **首选 Unicode 上下标**：`C₂v`、`³F₂`、`t₂g`、`ψ₂₁₀`、`cm⁻¹`
- **环境不支持时整体降级为平排**：`C2v`、`3F2`、`t2g`、`ψ210`、`cm-1`
- **绝不混用**：同一份答案里出现一半 `C₂v` 一半 `C2v`，比全用平排更失分

## 二、十四类记号的写法

### 1. 点群（Schoenflies）

```
C₂v    D₄h    T_d    O_h    D_∞h    C_∞v
```

主字母与轴次同行，轴次作下标，对称性后缀 v/h/d 跟在轴次之后。
**只写 Schoenflies 记号**，2–4 个字符；题干明确要国际记号才补 `mm2`、`4/mmm`。

语料依据：南开卷点群表格答案全是 `C2v / Oh / Td / D3d` 形态，无一处写中文。

错写：`C2V`（大写 V）、`C₂ᵥ`（后缀也做成下标）、`D4H`、`TD`（Td 的 d 是下标）。

### 2. 光谱项与光谱支项

```
³F     ³F₂     ²S₁/₂     ⁵D₄
```

多重度 (2S+1) → **左上标**；L → 大写正体 `S P D F G H I K`；J → **右下标**。J 为分数写 `1/2`，不写 `0.5`。

语料依据：南开卷答 `2S1/2`、`5D4`，并考「一个 ³D 项含 15 个微观状态」（= (2L+1)(2S+1) = 5×3）。

错写：`F3`（多重度当下标）、`3f`（L 写成小写）、`2S0.5`、d² 的基项只写 `3F` 漏 J（应为 `³F₂`）。

### 3. d 轨道在配位场中的分组

```
八面体：t₂g    e_g
四面体：e    t₂        ← 无 g/u
具体轨道：d_xy   d_yz   d_xz   d_z²   d_x²−y²
```

八面体的 `g` **不能漏**——它是对反演对称的标记，漏了等于漏了对称性。四面体无 i，故无 g/u。

语料依据：题库答案 55 处写 `t2g/eg`，教材 OCR 见 `t₂g⁶e_g⁰`。

错写：八面体写 `t2`（漏 g）、`dz2`、`x2-y2`（丢上标与负号）。

### 4. 不可约表示

```
一维 A/B，二维 E，三维 T
二级下标 1/2 → 对 C₂′ 或 σv 的对称性
三级下标 g/u → 对 i 的对称（只在含 i 的群里有意义）
撇 ′/″ → 对 σh 的对称性（D_nh）
```

**分解式用 `+` 连接，不用 `⊕`。**
语料依据：`⊕` 在三份语料里出现 **0 次**——教材一律写 `A1g + Eg + 2T1u`。

错写：`⊕`；漏 g/u；`A1’`（中文右单引号 U+2019，应为 prime U+2032）；`T₁u²`（重数 2 写在**前面**：`2T₁u`）。

### 5. 量子数

```
斜体 n、l、m；正体轨道名 2p、3d
```

`l`（小写 L）与数字 `1` 是最高频混淆点，尤其 `l=1` 处。`m_l` 与 `m_s` 必须带下标区分。

错写：`l=1` 写成 `1=1`、`L=1`（该用 l）、`m_l` 与 `m_s` 混。

### 6. 算符与量符号

物理量**斜体**（E、T、p、V、m）；单位与函数名**正体**（eV、sin、ln）；算符戴帽（`r̂`、`∇²`、`Ĥ`）。

语料依据：教材 OCR 里 `∂` 222 次、`∫` 230 次、`∇` 若干，算符一律带符号。

错写：`H` 与 `Ĥ` 不分、`▽2`。

### 7. 单位与量值

```
133 pm      2.27 Å      2143 cm⁻¹      5.14 eV      kJ·mol⁻¹      g·cm⁻³      12.0°
```

- 数值与单位间**空一格**
- 复合单位用**中点**（`kJ·mol⁻¹`），不堆斜杠（不写 `kJ/mol/K`）
- 角度带 `°`
- **波数用 ν̃（带波浪号），与频率 ν（Hz）区分**

语料依据：长度单位 `pm` 488 次 vs `Å` 165 次 —— **pm 是主用单位**，Å 只用于沿用题给值。
`cm` 的四种写法里 `cm-1` 307、`cm⁻¹` 4，均为提取 artifacts，规范用 `cm⁻¹`。

错写：`133pm`（不空格）、波数写成 `ν`（应 `ν̃`）、`2.270000 Å`（有效数字过多）。

### 8. 括号：晶面 / 晶向 / 晶面族

```
(hkl) 晶面      [uvw] 晶向      {hkl} 晶面族
分数坐标 (1/4, 1/4, 3/4)
```

三者不可混。负指数写 `h̄`（上划线）或 `-h`，同一份答案统一一种。

错写：晶面写成 `[hkl]`（那是晶向）、负指数漏上划线、分数坐标漏外括号。

### 9. 分数、根号、乘方

```
E = n²h²/(8mL²)        |L| = √(l(l+1))ħ        x² − y²
```

行内分数加括号避免歧义；根号覆盖整体；多字母乘积不留空格。

错写：`n2h2/8mL2`（读成 (n²h²/8m)·L²）、`√l(l+1)ħ`（漏外层括号）。

### 10. 有效数字

- **自己算的给 3 位**（题目给几位跟几位，一般不过 4 位）
- **查表常数照抄原位数**（74.05%、68.02%、34.01% 不重算）
- 中间量多留一位

语料依据：南开卷计算值 `2.27Å`、`0.899g·cm-3`、`58.9%`、`12.0°` 一律 3 位；表格常数 `74.05%` 照抄。

错写：3 位算成 6 位、`74.05%` 重算成 `74.0%`、角度不写小数。

### 11. 化学式与电荷

```
H₂O     [Cu(NH₃)₄]²⁺     K⁺     SO₄²⁻     CuSO₄·5H₂O
```

配离子整体加方括号，**电荷写在方括号外右上角**（`²⁺` 不是 `+2`）；水合物用中点 `·`。

错写：`Cu2+·4NH3`（拆了配离子）、`+2`、水合物用 `*`。

### 12. 中文与符号混排

- 结论句里**避免夹长公式**；必须夹时符号紧跟中文不加空格（`C2v 点群`、`3N−6 个振动`）
- 中文用全角标点，纯符号行用半角

语料依据：南开卷最长解释句 22 字——「因此环烯丙基负离子的键长要长于环烯丙基正离子。」全句无公式。

### 13. 表示与自由度记号

```
Γ_3N    Γ_vib    Γ_trans    Γ_rot
3N−6（非线性）    3N−5（线性）
```

`Γ` 是大写希腊 Gamma；下标写明是哪个表示。分解结果必须带**重数**（`3A₁ + A₂ + 3B₁ + 2B₂`），不能只列表示名。

错写：`Γ` 写成 `γ` 或 `r`、`Γvib`（缺下划线层次）、只写 `A₁ + B₁` 漏重数。

### 14. HMO 分子图三量

| 量 | 写法 | 图上位置 | 校验 |
|---|---|---|---|
| 电荷密度 | `q_r` | 原子旁 | `Σq_r = n_π` |
| 键级 | `P_rs` | 键上 | 总键级守恒 |
| 自由价 | `F_r = √3 − ΣP_rs` | 原子旁，最大处画箭头 | `F ≤ √3` |

自由价用精确 `√3`（苯 0.3987）还是 `1.732`（0.398），**选一种并在答案里说明**——不要两处位数不一致。

## 三、希腊字母消歧表（19 个，落笔前对照）

**每个字母至少两种含义，这是结构化学最大的符号陷阱。**

| 符号 | 含义一 | 含义二 | 含义三 | 判据 |
|---|---|---|---|---|
| `σ` | σ 键 / σ 型轨道 | **屏蔽常数**（无量纲） | **镜面** σv/σh/σd | 带数值无量纲→屏蔽；在点群记号旁→镜面 |
| `π` | π 键 / π 轨道 | **π 电子数** n_π | 大写 `Π` 线形分子 Λ=1 态 | 大小写分流键型与态 |
| `χ` | **特征标** χ(R) | 电负性 | — | 与群元/类→特征标；与元素→电负性 |
| `ν` | 频率（Hz） | **波数** `ν̃`（cm⁻¹） | 计量数 | **cm⁻¹ 的值必须用 ν̃** |
| `μ` | **偶极矩**（D） | **约化质量**（kg） | **磁矩**（BM） | 看单位，三者不可只写「μ」 |
| `α` | **HMO 库仑积分** | 晶胞夹角 α | 键角 / 极化率 | 与 β 并列→积分；带 °→角 |
| `β` | **HMO 共振积分** | 晶胞夹角 β | 转动常数是 `B` 不是 β | **B（拉丁）≠ β（希腊）** |
| `Δ` | **分裂能** Δo/Δt | 线形分子 Λ=2 态 | 差分 ΔE | 带 o/t 或 cm⁻¹→分裂能 |
| `Γ` | **表示** Γ_3N/Γ_vib | 伽马函数 | — | 带 3N/vib 下标→表示 |
| `E` | 能量（带单位） | **二维不可约表示** | 恒等操作 | 在 Γ 分解式里→表示 |
| `A/B/T` | 一维/三维不可约表示 | 系数/常数 | — | 在特征标表行首→表示 |
| `g/u` | 对 i 对称/反对称 | g 简并度 | — | **只在含 i 的群里有 g/u** |
| `P` | **键级** P_rs | **成对能** P（cm⁻¹） | ³P 态 | rs 下标→键级；与 Δo 比较→成对能 |
| `F` | **自由价** F_r | ³F 态（L=3） | 力 | 原子下标 r→自由价 |
| `q` | **电荷密度** q_r | 电荷 | — | 分子图语境，且须注明是 π 电子密度 |
| `ψ/φ/ϕ` | ψ 波函数 | φ 方位角 | φ 键角 / ϕ 试探函数 | 同题内 φ 只能一个意思 |
| `θ` | **Bragg 角** | 极角 | 键角 | 与 d、λ、n 一起→Bragg |
| `λ` | 波长 | **Λ 线形分子态** | — | 小写波长，大写 Λ 态 |
| `Z` | **核电荷** / Z\* 有效核电荷 | **晶胞式量数** Z（如 NaCl Z=4） | — | 带 \*→Z\*；与密度/晶胞→每胞式量数 |

## 四、高频错写清单（前 12 条，按出现频率排）

1. 波数用 `ν` 而非 `ν̃`（题库里 cm⁻¹ 类 312 处，全该是 ν̃）
2. 转动常数写成 `β`（应为拉丁 `B`）
3. 点群写 `C2V` / `D4H`（后缀大写）
4. 光谱项漏 J（d² 基项写 `3F`，应 `³F₂`）
5. 八面体 d 轨道漏 `g`（`t2` 而非 `t2g`）
6. 不可约表示分解用 `⊕`（教材从不这么写）
7. 重数写成上标（`T₁u²` 应为 `2T₁u`）
8. 单位与数值不空格（`133pm`）
9. 晶面写成 `[hkl]`（方括号是晶向）
10. 配离子电荷写成 `+2` 且在方括号内
11. `l`（小写 L）与数字 `1` 混
12. 同一题里 Z / μ / φ 承担两个含义

## 六、查表入口

工具 `sc_notation(query)` 可在线查本文任意条目：

```
sc_notation("σ")        → 4 个含义 + 判据 + 错写
sc_notation("点群")      → 点群写法 + 上下标规则
sc_notation("单位")      → 单位与量值写法
sc_notation("有效数字")   → 有效数字规则
sc_notation("")          → 全部符号索引 + 排版条目
```

数据源：`src/structchem_mcp/data/notation_rules.json`（19 符号 / 13 排版条目 / 14 条速查铁律）。
统计脚本：`tools/audit_notation.py`（可复跑，结论可复现）。
