## 一、光电子能谱（PES）：本课最核心的谱学

### 原理与 Koopmans 规则（原文）

> 光电子能谱和分子光谱都是分子轨道理论的实验基础，但两者的机理不同：分子光谱探测的是被物质吸收后的电磁波；
> 而光电子能谱探测的是被人射光从物质中击出的光电子的能量分布、强度分布和空间分布，其基本物理过程是光致电离
> `M + hν → M⁺* + e⁻`

```
轨道能量的负值 ≈ 被击出电子的结合能（电离能）        ← Koopmans（库普曼斯）规则
对闭壳层组态符合较好；开壳层/电子相关强的体系有偏差
```

**读图口诀**：横坐标是**电离能（或结合能）**，越靠**右**结合能越**大** → 该轨道被束缚得越紧 → 轨道能量越**低**。
> 原文：「当一个光子击出一个被束缚得较紧的电子时，光电子具有较低的动能」——动能小 ↔ 结合能大 ↔ 轨道深。

### 激发源（写实验条件时用）

| 谱 | 激发源 | 能量 | 能打出什么 |
|---|---|---|---|
| UPS | He I 线 | 21.22 eV | 价电子（分子轨道） |
| UPS | He II 线 | 40.8 eV | 价电子（更深一些） |
| XPS | Mg Kα | 1253.6 eV | 价电子 + **内层电子**（可做元素/价态分析） |
| XPS | Al Kα | 1486.6 eV | 同上 |

### 三条读谱带规则（原文，答题直接引用）

```
（1）一个非键电子电离：核间平衡距离几乎不变 → 谱带振动序列很短（峰尖锐）；
（2）一个成键或反键电子电离：核间平衡距离变化大 →
     成键电子电离使键长增大、反键电子电离使键长缩短 → 谱带序列比较长（峰宽、带精细结构）；
（3）若分子振动能级很密，或离子态与基态核间距相差很大 → 谱线表现为连续谱带。
```

### 教材实例：N₂ 与 O₂（连数据一起记）

| 电离的轨道 | 基本振动波数 /cm⁻¹ | 键长 /pm | 结论 |
|---|---|---|---|
| N₂（基态） | 2330 | 109.78 | — |
| N₂⁺（2σg 电离） | 2175 | 111.6 | 键长略增 → **2σg 弱成键** |
| N₂⁺（1πu 电离） | 1873 | 117.6 | 键长显著增 → **1πu 强成键** |
| N₂⁺（1σu 电离） | 2373 | 107.5 | 键长缩短 → **1σu 弱反键** |

由此可答三件事：① 分子轨道能级顺序（1πu 与 2σg 谁深谁浅）；② 各轨道的成键性质；③ "N₂ 的两对孤对电子在 MO 里不简并"（`1σu` 与 `2σg` 能量不同，虽然结构式里画成两对等同孤对）。

O₂ 的差别（原文指出）：`O₂` 的最高占据轨道是 `π*2p`，所以第一电离能比 N₂ **小**；
且 `π*2p` 有 2 个自旋相同电子，电离后剩余电子自旋取向不同会产生**两个谱带**。

### 自旋-轨道耦合分裂：用峰面积比推 l

```
从全充满轨道击出一个电子后，产生 j₁ = l + ½ 与 j₂ = l − ½ 两种状态，能量不同；
两峰面积比 = (2j₁+1) : (2j₂+1) = (l+1) : l
```

| 强度比 | 推得 l | 轨道 |
|---|---|---|
| **2 : 1** | l = 1 | p（如 Ar 的 3p，教材例题，见习题 3.34） |
| 3 : 2 | l = 2 | d |
| 1 : 0（不分） | l = 0 | s |

答题句：`Ar 的第一条谱线分裂为 2:1 两峰，由 (l+1):l = 2:1 得 l=1，故被电离的是 3p 电子。`

### 绝热电离能与垂直电离能（Franck-Condon）

```
绝热电离能 I_A：分子基态 → 分子离子基态（谱带第一个峰）
垂直电离能 I_v：分子基态 → 跃迁概率最高的振动态（谱带最强峰）
两者之差反映分子离子相对中性分子的核间距变化；变化越大，谱带越宽。
```

教材 H₂ 实例：`I_A = 15.43 eV`，谱带延伸至 18 eV，谱线间隔 `2200 cm⁻¹`（H₂⁺ 的振动能级差）。

## 二、X 射线光电子能谱（XPS）与化学位移

### 定义（原文）

> 将分子中某一内层电子 i 的结合能 `E_i(M)` 与自由原子中内层电子 i 的结合能 `E_i(A)` 之差定义为该分子的化学位移：
> `(ΔE)_i = E_i(M) − E_i(A)`

### 四条经验规律（原文，一字不改地记）

```
（1）原子失去价电子或与电负性高的原子结合而使价电子远离时，内层电子的结合能增大；
（2）原子获得电子时，内层电子的结合能减小；
（3）氧化态愈高，结合能愈大；
（4）价层有某种变化，所有内层电子的结合能也有相应变化。
```

**方向绝不能反**：氧化态高 → 结合能**大** → 谱峰向**高结合能方向**移动。

### 峰强度经验规律

```
主量子数 n 小的壳层峰更强；同一壳层，l 大者峰强；n 与 l 都相同时，Z 大者峰强。
```

### 两个标准例子（可以直接当模板）

| 体系 | 谱图特征 | 结论 |
|---|---|---|
| Na₂S₂O₃ vs Na₂SO₄ | 前者 S 2p 区**两个峰**，后者**一个峰** | S₂O₃²⁻ 中有两类硫：与 O 相连的硫带正电荷、结合能大；末端硫带负电荷、结合能小 |
| B₅H₉ | B(1s) 有**两个强度比 4:1** 的峰，小峰结合能较小 | 4 个 B 处于同一化学环境，另 1 个 B 电子密度较高（亲核性）→ 结构为四方锥形 |

答题句式：`谱峰个数 = 该元素所处的化学环境数；峰强度比 = 各环境原子数之比；结合能越大 = 该原子电子密度越低/氧化态越高。`

## 三、紫外-可见光谱与 Franck-Condon 原理

```
电子跃迁：ΔE = hc/λ；选律 ΔS = 0（自旋允许），Δl = ±1（原子）；分子中对称性要允许（与偶极矩同表示）
Franck-Condon：电子跃迁比核运动快得多 → 跃迁在"核间距不变"的垂直线上发生 → 垂直跃迁概率最大
```

教材 H₂ 实例：`(σ1s)² → (σ*1s)(π2p)` 跃迁时，**强度最高的谱线对应 v=0 → v'=3**，即核间距不变的那条垂直线。
→ 答题要点：**谱带最强峰 ≠ 能量最低跃迁**；能量最低的是 0→0（绝热），最强的是垂直跃迁。

配合物的 d-d 跃迁见 `coordination.md`（Δo 越大，吸收波长越短）。

## 四、红外与拉曼：只考选律，不考经验位移表

### 两条选律（与 `symmetry-playbook.md` 第七节同一套，这里给物理表述）

```
IR 活性：振动引起偶极矩变化（Δμ ≠ 0）↔ 模式的不可约表示与 x, y, z 相同
Raman 活性：振动引起极化率变化（Δα ≠ 0）↔ 模式的不可约表示与二次函数相同
互斥规则：分子有对称中心 i 时，IR 与 Raman 互斥
```

### 常见判断（卷面直接给）

| 分子/离子 | 点群 | 结论 |
|---|---|---|
| H₂O | C2v | 3 个振动全 IR + Raman 活性 |
| CO₂ | D∞h | 对称伸缩 Raman 活性、IR 非活性；反对称伸缩与弯曲 IR 活性、Raman 非活性（互斥） |
| N₂、O₂（同核双原子） | D∞h | 无 IR 吸收（无偶极矩变化），只有 Raman |
| CO（异核双原子） | C∞v | 有 IR 吸收 |
| SF₆ | Oh | 只有 T1u 模式 IR 活性；A1g/Eg/T2g Raman 活性；T2u 静默 |
| 苯 | D6h | IR 活性只有 E1u 与 A2u（与 z 同表示）；Raman 活性为 A1g、E1g、E2g |

### 与有机化学的分工边界（写清楚，别越界）

| 归本 skill（结构化学） | 归 `organic-chem-answering`（有机） |
|---|---|
| 选律、活性判定、互斥规则 | 特征频率经验值（1700 cm⁻¹ = C=O 之类） |
| 用对称性算振动模式数 | 用峰位推官能团 |
| 群论归属（A1g/B1u…） | ¹H NMR 的 δ 位移区间、n+1 裂分 |
| 分子对称性 ↔ 等价核数 | 复杂偶合常数、NOE |

**结构化学里出现 NMR，只考两件事**：① 由对称性推"有几种不等价核"（信号数）；② 固体高分辨（MAS）用于确认等价性。
不考位移经验表——那是有机的题。

## 五、谱学题的四类问法与骨架

| 问法 | 骨架 | 工具 |
|---|---|---|
| 由 UPS 谱带形状判断轨道成键性质 | 电离的是哪个轨道 → 键长/振动波数怎么变 → 成键/非键/反键 | `sc_diatomic_mo`（比对组态与键级） |
| 由峰面积比推轨道角量子数 | 面积比 (l+1):l → l → 轨道名称 | — |
| 由 XPS 峰数与强度比推结构/价态 | 峰数 = 环境数；强度比 = 原子数比；结合能大 = 氧化态高 | — |
| 判断某振动是否 IR/Raman 活性 | 点群 → 基函数 → 选律 → 逐模式列 | `sc_normal_modes`、`sc_character_table` |

**答题字数纪律**（与 `answer-style.md` 一致）：一句判据 + 关键数据，**不超过 3 句**。
例：`Ar 第一条谱线分裂为 2:1 两峰，由 (l+1):l=2:1 得 l=1，故被电离的是 3p 电子。`（35 字，含数据）

## 六、常考陷阱

1. Koopmans 规则方向反：把"结合能 = 轨道能量"写成同号（应为**轨道能量的负值**）。
2. 把 UPS 横坐标当"动能"读：教材惯用**电离能/结合能**做横坐标，向右变大。
3. 认为"成键电子电离后谱带更窄"——反了：**成键/反键电离 → 核间距变化大 → 谱带更宽更长**。
4. 自旋-轨道分裂的强度比写成 (2j+1) 却代错 j；记成 (l):(l+1) 也不对，是 **(l+1):l**。
5. XPS 化学位移说成"氧化态越高结合能越小"。
6. 认为同核双原子分子有 IR 吸收（无偶极矩变化 → 无 IR，只有 Raman）。
7. 有对称中心的分子答出某个模式 IR、Raman 同时活性（违反互斥规则）。
8. 把 Franck-Condon 的"最强峰"说成"能量最低的跃迁"。
9. 用有机化学的 ¹H 位移表去答结构化学 NMR 题（口径不对，且本课不考）。
