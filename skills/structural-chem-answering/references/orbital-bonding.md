# 分子轨道与化学键（HMO · 芳香性 · 双原子 · VSEPR）

覆盖教材第 3 章。核心是一条确定性流程：**久期行列式 → 能级 → 系数 → 分子图**。
凡是拓扑确定的共轭体系，一律用 `sc_huckel` 算，不要手推行列式展开。

---

## 一、HMO 法的前提（答题时一句话交代即可）

```
① σ-π 分离：只处理 π 电子，σ 骨架当作固定框架；
② 每个参与共轭的原子提供一个 p 轨道；
③ 库仑积分 α（各原子相同）、相邻共振积分 β（各键相同，β<0）、非相邻作用取 0；
④ 重叠积分近似取 S=0；
⑤ 解 |H − ES| = 0 → 令 x = (α − E)/β，化成只含 x 的久期行列式。
```

能量写法固定为 `E = α + xβ`。**`x` 越大能量越低**（因为 β<0），所以 `x = −2` 的能级最低。

---

## 二、完整流程（南开计算题第 1 题的标准答案形态）

以环丙烯正离子（3 元环、2 个 π 电子）为例：

```
① 久期行列式
        | x  1  1 |
        | 1  x  1 | = 0        （按 x=(α−E)/β 归一后）
        | 1  1  x |
   展开：x³ − 3x + 2 = 0 → (x−1)²(x+2) = 0 → x = −2, 1, 1

② 能级
   E₁ = α + 2β（非简并）
   E₂ = E₃ = α − β（二重简并）

③ 系数（回代久期方程组 + 归一化）
   x=−2 → c₁=c₂=c₃ → ψ₁ = (1/√3)(φ₁+φ₂+φ₃)
   x= 1 → c₁=−2c₂, c₂=c₃ 与 c₂=−c₃ 两支：
          ψ₂ = (1/√6)(2φ₁−φ₂−φ₃)    ψ₃ = (1/√2)(φ₂−φ₃)

④ 电子填充（Pauli + 能量最低）：2 个 π 电子全进 ψ₁

⑤ 电荷密度   q_r = Σ_i n_i c_ir²        → q₁=q₂=q₃ = 2×(1/3) = 0.667
⑥ 键级       P_rs = Σ_i n_i c_ir c_is    → P₁₂=P₂₃=P₃₁ = 2×(1/3) = 0.667
⑦ 自由价     F_r = √3 − Σ_{s 与 r 相邻} P_rs
             → F = 1.732 − 2×0.667 = 0.398
⑧ 分子图     原子旁标 q 与 F，键上标 P
⑨ 比较       环丙烯负离子（4π：ψ₁²ψ₂²）的 P = 0.333 < 0.667，故负离子键长更长
```

**卷面必须有的四样**：行列式、x 值、α/β 形式的能级、分子图。少一样就少一段过程分。

### 数字口径（南开原文与工具一致）

- 自由价有时写成 `4.732 − 3 − ΣP`，与 `1.732 − ΣP` **数值相同**（4.732−3 = 1.732 = √3）。
  两种写法都给分，但减的对象必须是**与 r 直接相邻的键**。
- q、P、F 一律 **3 位小数**（0.667、0.398、0.974）。
- 能级必须带 `α`、`β`；离域能必须带 `β`（例：环丙烯正离子离域能 = 2β）。

## 四、芳香性（四条件逐条写，别只写 4n+2）

```
① 环状（或环状共轭体系）
② 平面（或接近平面，使 p 轨道平行重叠）
③ 完全共轭（每个环原子都有一个 p 轨道参与）
④ π 电子数 = 4n + 2（n = 0,1,2,…）
```

| 体系 | π 电子 | 判定 |
|---|---|---|
| 苯 | 6 | 芳香（4n+2, n=1） |
| 环丙烯正离子 | 2 | 芳香（n=0） |
| 环戊二烯负离子 | 6 | 芳香（n=1） |
| 环庚三烯正离子（䓬离子） | 6 | 芳香（n=1） |
| 环丁二烯 | 4 | **反芳香**（4n）：平面时双自由基，实际畸变为长方形 |
| 环辛四烯 | 8 | 非芳香：4n 且**盆形非平面** |
| 萘 | 10 | 芳香（n=2） |

答题要点：**判"非芳香"要说清是哪一条不满足**（平面性 / 完全共轭 / 电子数）。
"是 4n+2 所以芳香"这句话单独出现时，只能拿一半分。

## 五、双原子分子的 MO

### 能级顺序（本课第一大陷阱）

```
第二周期前段（B2、C2、N2 及更轻）： σ2s < σ*2s < π2p < σ2pz < π*2p < σ*2pz
第二周期后段（O2、F2）：           σ2s < σ*2s < σ2pz < π2p < π*2p < σ*2pz
```

原因：N2 及更轻 s-p 混杂强，σ2pz 被推高到 π2p 之上；O2/F2 核电荷更大，s-p 混杂弱，σ2pz 落回 π 之下。
**写反一处，整张 MO 图与键级讨论连带作废。**

### 组态与性质表

| 分子 | 价电子数 | 组态要点 | 键级 | 单电子 | 磁性 |
|---|---|---|---|---|---|
| H2 | 2 | σ1s² | 1 | 0 | 抗磁 |
| He2 | 4 | σ1s²σ*1s² | 0 | 0 | 不存在 |
| Li2 | 6 | …σ2s² | 1 | 0 | 抗磁 |
| Be2 | 8 | …σ*2s² | 0 | 0 | 不存在 |
| B2 | 10 | …π2p² | 1 | **2** | **顺磁** |
| C2 | 12 | …π2p⁴ | 2 | 0 | 抗磁 |
| N2 | 14 | …π2p⁴σ2pz² | **3** | 0 | 抗磁 |
| O2 | 16 | …σ2pz²π2p⁴π*2p² | **2** | **2** | **顺磁** |
| F2 | 18 | …π*2p⁴ | 1 | 0 | 抗磁 |
| Ne2 | 20 | 全满 | 0 | 0 | 不存在 |
| NO | 15 | …π*2p¹ | **2.5** | **1** | **顺磁** |
| CO | 14 | 与 N2 等电子 | 3 | 0 | 抗磁 |

键级：`键级 = (成键电子数 − 反键电子数)/2`。**分母的 2 是最常漏的一处。**

### 键长/键能趋势题怎么写

```
键级越大 → 键长越短、键能越大。
N2(3) < NO(2.5) < O2(2) < F2(1)：键长依次增大、键能依次减小。
O2⁺(2.5) < O2(2) < O2⁻(1.5) < O2²⁻(1)：同一趋势。
```

## 六、VSEPR（价层电子对互斥）

```
① 算中心原子的价层电子对数 = 成键电子对数 + 孤电子对数
   （孤对 = (中心价电子数 − 配体成单电子数之和)/2，注意离子电荷加/减）
② 写 AX_mE_n 记号
③ 由电子对构型去掉孤对 → 分子构型 → 点群 → 键角（说明偏离理想值的方向）
```

| 类型 | 电子对构型 | 分子构型 | 点群 | 例 |
|---|---|---|---|---|
| AX2 | 直线 | 直线 | D∞h | CO2, BeCl2 |
| AX3 | 平面三角 | 平面三角 | D3h | BF3, SO3 |
| AX2E | 平面三角 | 弯曲 | C2v | SO2, O3, NO2⁻ |
| AX4 | 四面体 | 四面体 | Td | CH4, SO4²⁻ |
| AX3E | 四面体 | 三角锥 | C3v | NH3, PCl3 |
| AX2E2 | 四面体 | 弯曲 | C2v | H2O, H2S |
| AX5 | 三角双锥 | 三角双锥 | D3h | PCl5 |
| AX4E | 三角双锥 | 跷跷板 | C2v | **SF4** |
| AX3E2 | 三角双锥 | T 形 | C2v | **ClF3** |
| AX2E3 | 三角双锥 | 直线 | D∞h | XeF2 |
| AX6 | 八面体 | 八面体 | Oh | SF6 |
| AX5E | 八面体 | 四方锥 | C4v | BrF5 |
| AX4E2 | 八面体 | 平面四方 | D4h | XeF4 |

斥力顺序：`孤对–孤对 > 孤对–成键 > 成键–成键`。所以 H2O（104.5°）< NH3（107.3°）< CH4（109.47°）。

**杂化的用法**：杂化只是"把构型翻译成 VB 语言"的记号。第二周期中心（C/N/O）用 sp/sp²/sp³ 可靠；
第三周期以后（S 的 sp³d、sp³d²）只是形式记号，**判构型仍按 VSEPR 电子对数走**，不要用杂化去反推。

## 七、离域 π 键（Π_n^m 记号）

`Π_n^m`：n = 参与共轭的原子数，m = 离域 π 电子数。

| 分子/离子 | 离域键 | 说明 |
|---|---|---|
| 苯 | Π₆⁶ | 6 个 C 各 1 个 p 电子 |
| 丁二烯 | Π₄⁴ | 两个双键共轭 |
| CO3²⁻ / NO3⁻ / SO3 / BF3 | Π₄⁶ | 中心原子提供 1 对电子或 1 个电子，按等电子体一致处理 |
| O3 / NO2⁻ | Π₃⁴ | 中心 1 对 + 两端各 1 |
| CO2 / N2O | 两个 Π₃⁴ | 分别朝两个方向 |
| 石墨层 | 大 Π 键 | 层内完全离域 |

答题格式：`CO3²⁻ 中存在 Π₄⁶ 离域 π 键，故三个 C–O 键长相等`。
——**离域的最直接实验证据是"键长平均化"**，解释题写这一句最稳。

## 八、分子图规范（画错或漏标就是丢分）

```
原子旁：q_r（电荷密度）+ F_r（自由价，可加小箭头指向该原子）
键上：  P_rs（键级）
必要时标能级与电子组态
```

南开真题的分子图就是这样标的：原子上写 `0.622 / 1.047 / 1.093 / 1.073`，键上写 `0.758 / 0.449 / 0.778 / 0.520`，
原子旁再列 `0.974 / 0.076 / 0.505 / 0.434`（自由价）。
→ **三个量都要出现，缺一个就不算"画出分子图"。**

判反应活性（亲电取代位点）的判据：自由价 F 大者活性大（或电荷密度 q 大者）。
题目说"不要求计算过程"时，可以直接给结论（如真题答案 `反应位置在 3、6 位`）。

## 九、工具映射

| 要做的事 | 工具 |
|---|---|
| 久期行列式、x、能级、系数、q/P/F、离域能、简并 | `sc_huckel(topology="linear"/"cyclic"/"ring"+adj, n_electrons)` |
| 4n+2 判定与理由、反例 | `sc_aromaticity(n_pi, n_atoms, ring)` |
| 双原子组态、键级、单电子、磁性、键长趋势 | `sc_diatomic_mo(n_electrons, period, homo)` || 价层电子对数、AX_mE_n、构型、点群、键角 | `sc_vsepr(central, ligands, lone_pairs)` |

**调用纪律**：拓扑一定要说清（`linear` 链 / `cyclic` 环 / 自定义 `adj` 邻接矩阵）。
环丙烯是 3 元环，写成链会得到完全不同的能级（链：α+1.414β；环：α+2β）——那是两道不同的题。
`sc_diatomic_mo` 的 `n_electrons` 传**分子总电子数**（O₂=16、N₂=14、NO=15、CO=14），
价电子数由工具内部折算并写进 `steps`；**不要自己先减成价电子再传**，那样会少填一层内层轨道。
